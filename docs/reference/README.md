# Reference

Lookup pages for installing, upgrading and configuring TMB, and for finding where its state lives.

## Index

- [INSTALL.md](INSTALL.md) — How to install TMB per project at project or local scope, and why user scope is not recommended.
- [UPGRADE.md](UPGRADE.md) — What moves when you upgrade (plugin files and the trajectory DB), what to expect, and how to roll back.
- [CONFIG_KEYS.md](CONFIG_KEYS.md) — Every `plugin_config` key with its type, default, writer and effect. Generated from the keys the code reads and writes.
- [TRAJECTORY_DB_LOCATION.md](TRAJECTORY_DB_LOCATION.md) — The one rule that decides which `trajectory.db` the MCP server and every hook use.
- [REFERENCE.md](REFERENCE.md) — Occasional lookups for bro, kept out of CLAUDE.md: where state lives, and the full list of MCP tools.
