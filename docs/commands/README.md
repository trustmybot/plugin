# Commands Catalog

Slash commands available in Claude Code when the TMB plugin is active.

Each command file lives in `plugin/commands/<name>.md`. For the full deterministic skill logic behind a command, see the corresponding entry under `skills/`.

/roundtable — Multi-agent deliberation on a topic with checkbox/radio AUQ ratification
/monitor — Pull PR/MR review comments and dispatch SWE tasks to address them
