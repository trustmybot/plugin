How TMB writes and enforces its prompts: personas, agent files, skills and commands, and when a rule belongs in code instead of a prompt.

- [GOLDEN_PROMPTS.md](GOLDEN_PROMPTS.md) — The guide for writing and checking a prompt: yes/no criteria in the order a prompt is written, with real examples and the eval set it requires.
- [PROMPT_ENGINEERING.md](PROMPT_ENGINEERING.md) — The research reference behind those criteria: each rule with how strong its evidence is and where that evidence comes from.
