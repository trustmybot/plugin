### Fixed
- **The close-time scope gate counts only the task's own commits** (GH 1299): `bro_atomic_close` diffed against the task's recorded base, so commits dev gained after a task branched counted as out-of-scope changes and needed a waiver that hid real scope creep. It now diffs `merge-base(commit, origin/<pr_target>)..commit` (`pr_target` from the repo row, else the task's parent branch, else `dev`). When the task's recorded base differs from that merge-base the close result carries `base_moved: true` with `recorded_base` and `merge_base`, and a `scope_gate_waived` row records all three.
