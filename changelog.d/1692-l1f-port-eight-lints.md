- **Eight more L1 lints run on node:test** (GH 1692, the runtime hook TypeScript port): `no-kuzu-in-prompts`, `no-audit-log-without-from-node`, `stale-framing-prose`, `ci-workflow-refs-exist`, `no-bare-mktemp`, `release-payload-workflow`, `no-home-writes` and `no-module-load-writes` move from bash to `tests/l1-lint/<name>.test.mjs` with the same checks, scan targets, allowlists, exemptions and failure messages; the perl scanners are now JavaScript, and `release-payload-workflow` still parses the workflow with `ruby -ryaml`.
