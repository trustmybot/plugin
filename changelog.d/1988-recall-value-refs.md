### Added
- **The world model sees functions passed as values, static receivers, `extends` and JSX components as callers** (GH 1988): the TS/TSX symbol index now records a `calls` edge when a function or class that a file imports or declares at module level is passed as a call argument, put in an object, array, return value, assignment or export, or used as a static-call receiver (`Klass.staticFn()` also reaches `Klass`), and an `instantiates` edge for `class Sub extends Base` and for each capitalized JSX element (`<Button />`). Locals and parameters of the same name are skipped, and an `import { A as B }` alias now reaches `A`. Impact, `world_model_symbol` callers and `diffDownstream` see these callers after the next scan, which re-indexes every TS file.
