### Changed
- The L1-L4 test orchestrator is TypeScript (GH 1692): `node --experimental-strip-types tests/run-all.ts [--l1-only]` replaces `bash tests/run-all.sh` and does what it did — the payload build, every L1-L4 step with the same labels, `→ PASS` / `→ FAIL` / `→ SKIP (TMB_L1_SKIP)` lines, the gh/glab/claude stubs (now Node scripts) and live-CLI sentinel checks, the run-scoped tool caches, the empty-HOME footprint check and the summary. `bun run test`, the PR check and the release gate call it, and the test-run suite slot treats it as a full suite. `tests/run-all.test.ts` covers its helpers as an L3 step. The unused `tests/lib/assert.sh` is gone.
