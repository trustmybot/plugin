### Fixed
- **Semantic search works from the first session on a new plugin version** (GH 1748): the trajectory server starts at the same time as the SessionStart hook that links `@huggingface/transformers` into the server's directory. If it got there first, it couldn't find the package and embeddings stayed degraded until the retry a minute later, even though the package was already installed in the plugin data dir. The server now imports transformers from `$CLAUDE_PLUGIN_DATA/deps/<key>/` first and falls back to the normal package lookup, so embeddings are ready at startup. When neither loads, `trajectory_doctor` reports both places it looked.
