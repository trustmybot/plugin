### Fixed
- **The cold-start banner counts source files across a workspace's registered repos and prints a single `0` on an empty tree** (GH 1367): `session-start-prescan.sh` ran `git ls-files` in the hook's cwd, so a workspace-pattern project (root not a git repo, child repos in the `repos` table) always read `0 source files`, and `grep -c … || echo 0` printed `0` twice on zero matches, so the banner read `cold (no scan yet; 0\n0 source files)` and the cold-start auto-scan gate misfired. The count now sums the tracked, non-excluded files of every existing `repos.path` (falling back to the cwd when the table has no rows) and is always one integer.
