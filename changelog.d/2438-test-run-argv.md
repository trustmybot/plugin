### Fixed
- **`test-run` runs the argv after `--` as given, with no shell** (GH 2438): joining the words and re-running them through `bash -c` split quoted arguments again, so `--test-name-pattern='GH 1954|GH 1834'` became a pipe into `GH 1834`. Every argv, one word or several, now spawns `argv[0]` with the rest as its arguments; shell syntax goes through `-- bash -c '<cmd>'`. A shell builtin or `VAR=value` as the first word (`-- exit 3`, `-- FOO=1 node --test x`) exits 2 without running and prints `use -- bash -c '<cmd>' for shell syntax`; a program that is not found exits 127 with the same hint on stderr and in the log, instead of a silent 127 with an empty log. Full suites are recognised from the argv, including the script of a `bash -c`.
