### Changed
- The ensure-gitignore, ensure-mcp-deps-installed, mcp-health-check, deferred-tools-drift-warn and substrate-preflight hook tests are now node:test files under `mcp/trajectory-server/src/test/` that run in `npm test`, with every assertion kept (GH 1692). The ensure-mcp-deps-installed cases join the existing `ensure-mcp-deps-installed.test.ts`, which now also covers the legacy install's ready, lock-held, npm and state-dir paths. The five `tests/l3-integration/hooks/*.test.sh` files are gone.
