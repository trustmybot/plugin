- **Project skill and agent files change only on the Human's approval** (GH 2927): an Edit, Write or MultiEdit of a file under your project's `.claude/skills/` or `.claude/agents/` is now blocked unless bro recorded the Human's AskUserQuestion Yes for that exact path in the last 30 minutes, as a `prompt_write_approved` audit event. - **`tmb_skill-creator` and `/tmb:agent-create` record the Human's approval before writing** (GH 2927): after your Yes, bro records a `prompt_write_approved` event for each file it then writes (scope `full` for a new skill or agent file, `skills-array` for each agent the skill attaches to), so these flows pass the approval gate. `skill_register` now refuses a name that is already registered, naming the existing skill and its file, instead of failing on a bare database constraint.
