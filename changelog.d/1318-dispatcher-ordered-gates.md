### Security
- **The trajectory-server gates run in one order and stop at the first deny; a host without jq fails closed** (GH 1318): Claude Code runs every hooks.json entry of a matcher in parallel, so a call `agent-arg-matches-caller` denied still reached its sibling gates — a pr-reviewer `validation_record` with `agent='bro'` left a `reviewer_identity_observed` row, and a main-session `task_update_status(agent='swe')` could record a verification run. The five `mcp__.*trajectory-server__*` entries are now one registration, `dispatch.sh trajectory-gates`, which runs `agent-arg-matches-caller`, `swe-brief-gate`, then `swe-verification-gate`, `reviewer-identity-observe` or `cheatcode-install-approval` by tool name, one after another, and returns the first deny; each gate keeps its own dedupe key and lock, and the allowing gates' context is joined into one output. Each gate runs in its own process group under a watchdog at its own timeout (a gate past it is killed with everything it started and the chain denies; no process-tree walk, so it holds without pgrep), any exit other than 0 or 2 ends the chain with a deny, a duplicate chain (user and project installs) whose waiter gives up ends without running later gates, and a chain stays fail-closed without hooks.json or its registration library. The headless shim (`/onboard`) now registers `trajectory-gates`, so headless runs get `swe-brief-gate` enforcement as well. Without jq every dispatcher gate used to allow — the gates exited 0 and `dispatch.sh` needed jq to read `onFailure` — so `onFailure: block` never took effect: the dispatcher now reads its registration with awk and a fail-closed gate denies with `jq not found`, the deny-capable gates that check for jq exit 1 naming it, `reviewer-identity-observe` allows with a stderr note, and the SessionStart prescan prints `Tooling: jq not found — every TMB gate will deny until it is installed`. `hook-onfailure.sh` fails a deny-capable gate that allows silently without jq; `hooks-via-dispatcher.sh`, `hook-timeout-budget.sh` (the chain's timeout covers its gates in sequence) and `hooks-doc-fresh.sh` expand the chain into its gates.
