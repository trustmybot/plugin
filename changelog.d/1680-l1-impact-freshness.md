### Added
- **Symbol cards show impact, source and staleness, and the world model catches up on start** (GH 1680): `world_model_symbol` takes `impact` (`true` for 2 hops, or 1–5) to list the callers of a symbol hop by hop plus the tests they reach, capped at 200, and `source: true` to return its body from disk (up to 200 lines, framed as untrusted content). Symbol cards and symbol search hits carry `stale: true` when the file changed since the last scan, so an answer from an out-of-date index says so. When the trajectory server starts it runs a background catch-up scan, so edits made while no session was open are indexed before the first query (`TMB_SKIP_AUTO_RESCAN=1` turns it off). Symbol stamps now include an extractor version, so the first scan after an extractor fix re-parses every file once.
