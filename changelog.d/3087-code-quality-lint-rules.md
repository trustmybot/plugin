### Added
- **Three more edit-time code warnings** (GH 3087): when swe or you edit a Python or TypeScript/JavaScript file, code-quality-lint now also warns about a script entry check that compares `process.argv[1]` with `import.meta.url` directly (it silently fails when run through an npm bin symlink or a symlinked checkout), a `spawnSync`, `execSync` or `execFileSync` call with no `timeout` (a hung child process blocks forever), and a hardcoded `/Users/<name>/` or `/home/<name>/` path in a string outside test files. The warnings arrive while the code is written, a review round earlier than before, and never block the edit.
