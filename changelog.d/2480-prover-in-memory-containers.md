### Fixed
- **Read-only `node -e` programs that fill arrays, Maps or Sets are no longer denied** (GH 2480): the containment guard read `t.push(1)`, `pop`, `shift`, `unshift`, `splice`, `reverse`, `sort`, `fill`, `new Set().add` / `has`, `new Map().set` / `get` / `has` / `delete` / `clear`, `[…].filter(Boolean)` and a required `.json` used as a value (`const r=require("./r.json"); Object.keys(r)`) as unproven and denied the command, though they only touch process memory. They now prove; a `sort` comparator is checked like any other callback. A required builtin module used as a value (`[require("child_process")].map(…)`), a comparator that calls an unknown function, and a mutator on `process.argv` / `env` are still denied.
