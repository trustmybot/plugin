### Changed
- **The MCP server's semantic-search runtime is installed once, about 45 MB instead of about 400 MB per plugin version** (GH 1695): the SessionStart hook `ensure-mcp-deps-installed` now runs from TypeScript and installs `@huggingface/transformers` 3.8.1 from a committed lockfile into `$CLAUDE_PLUGIN_DATA/deps/<version>-<platform>-<arch>/`, shared by every plugin version. It keeps only this host's onnxruntime prebuilt, drops onnxruntime-web, sharp and the browser builds, checks that the package imports, then switches `deps/current` to it and keeps one previous install. Each plugin version reaches it through a `node_modules/@huggingface/transformers` symlink, so a plugin update no longer reinstalls, and older versions' hook-installed `node_modules` in the same plugin cache are replaced by that symlink. A real `node_modules` directory, such as a dev checkout's, is never replaced. Without `CLAUDE_PLUGIN_DATA`, or on Windows, the hook installs into the plugin as before. `TMB_SKIP_MCP_DEPS_INSTALL=1` still turns it off and `TMB_HOOKS_IMPL=bash` still runs the old script.
