### Added
- **A pr-reviewer spawn first passes five deterministic checks** (GH 1740): before the reviewer starts, the new `pr-reviewer-preflight` gate checks that the task branch tip is the recorded commit, that a passing verification run is recorded for that commit, that the commit merges into the PR target without conflicts, that no agents/, skills/ or docs/ page, `CLAUDE.md` or `README.md` still names a path or MCP tool the change removes, and that a `changelog.d/` fragment was added when the repo uses them. The first failing check denies the spawn with a JSON reason `{check, expected, actual}`, so no reviewer is spent on work a machine can refuse. Set `TMB_SKIP_PR_REVIEWER_PREFLIGHT=1` to bypass it.
