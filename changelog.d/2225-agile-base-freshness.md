### Fixed
- **Agile tasks are checked against their milestone feature branch, not dev** (GH 2225): in agile mode, a task stacked on a feature branch is now measured against that branch for the worktree freshness check, the close-lint base, the close-time changelog and doc diff, the reviewer's lint-record check and the reviewer's changed-symbol context. Before, every check measured from dev, so a fresh task on a feature branch ahead of dev was flagged stale and its diff took in the feature branch's own commits. The feature branch is read from origin when it is there, else locally; a parent that does not resolve, and every task in truest mode, keep the dev-first order.
