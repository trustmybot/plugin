### Added
- **Per-repo worktree setup step** (GH 2054): a repo can list build commands in `.config/tmb/worktree-setup.json` (`{"version":1,"commands":[...]}`), and every worktree TMB makes runs them after linking `node_modules`. `task_provision`, `task_reopen` and `task_retry` report a failure in `worktree_setup` and still provision; `cli.js integrate` exits 1, `pr_monitor_worktree` returns an error, and the swe verification gate denies the close, each naming the failing command and its output. A repo without the file sees no change. This repo's file runs `bun run build:payload`, and `tests/run-all.sh` runs it before the L1 lints.
