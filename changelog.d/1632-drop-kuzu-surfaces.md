### Changed
- **The last Kuzu leftovers are gone** (GH 1632): sessions no longer start a background install of the Kuzu native binary, and the health check (`scripts/health.sh`) now checks the world model where it lives — it reads the trajectory DB (read-only, never writing or deleting anything) and passes when the `wm_directories` / `wm_files` tables are present, warns with a pointer to `/scan` when they are empty, and fails with a restart hint when they are missing. When an old `world-model.kuzu` graph from before the move is still beside the DB, the health check names it as an unused leftover you may delete; TMB never removes it for you. The recovery skill, `/scan`, the README and the plugin description now describe the world model as tables in the trajectory DB.
