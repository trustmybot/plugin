### Changed
- **A pull request runs only the L1 lints its changes reach** (GH 3161): every L1 step in `tests/run-all.ts` now declares the paths it reads, and the new `--l1-changed` mode runs only the steps whose paths the diff against `--base <ref>` (else `TMB_LINT_BASE_SHA`) touches, printing `→ SKIP (--l1-changed)` for the rest. A change to a shared input (`package.json`, `bun.lock`, a `tsconfig*.json`, `tests/run-all.ts`, `tests/l1-lint/`, `tests/lib/`, `.config/tmb/`), a missing base or a failing `git diff` runs the full L1, and a new self-check fails on any L1 step that declares no paths. pr-check runs `--l1-changed` against the PR's base branch, merge-queue runs keep the full `--l1-only`, and the close lints run `--l1-changed`, with the close-lint runner passing the recorded base to each lint as `TMB_LINT_BASE_SHA`.
