### Changed
- **World model search and symbol lookup cover every repo when none is picked, `name` works as an alias, and a missing `agent` is reported as a missing argument** (GH 2417): with two or more registered repos and a cwd inside none of them, `world_model_search` now searches every repo and merges the hits by score (`repo_source: 'all'`, `repos_searched`) instead of returning no results, and `world_model_symbol` looks a name up in every repo, returning the one match or the `ambiguous` list with each match's repo. `world_model_get` and the concept tools still return `repo-unspecified`. `world_model_symbol` accepts `name` as an alias of `qualified_name` (`qualified_name` wins when both are given). A call with no or an invalid `agent` now returns `error: 'missing_argument'` with `argument: 'agent'` instead of `error: 'forbidden'`; a known role a tool does not admit still gets `forbidden`.
