### Fixed
- **A verification command written as a prose sentence is now refused when the task is written, not run by the close gate** (GH 2955): `task_provision`, `task_retry`, `task_reopen` and `task_update_spec` refuse a `verification[]` entry whose command word is a capitalized English word that runs as nothing (not on PATH, not a shell builtin, not a path), such as `Run schema-upgrade.test and confirm all cases pass`, with `verification_not_command` naming the entry and the word, and write nothing. Before, the close gate ran the sentence as shell and failed with exit 127. Lower-case commands missing from PATH are still accepted.
