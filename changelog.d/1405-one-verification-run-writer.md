### Changed
- **`cli.js integrate` records its verification run through the same writer as the swe-verification-gate** (GH 1405): integrate no longer keeps its own copy of the `verification_runs` and `verification_run_commands` SQL. It builds its run start, command rows and finish with the gate's builders in `hooks/lib/verification-runs.ts`, and its runs still carry `source = 'manual'`. One behavior changes: integrate now follows the gate's output-tail rule, so `TMB_VERIFICATION_TAIL_CHARS=0` keeps a command's whole output tail. Before, integrate cut the tail to nothing under a C locale.
