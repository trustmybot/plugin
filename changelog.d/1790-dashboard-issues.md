### Changed
- **Dashboard issues look like GitHub issues** (GH 1790): the Issues tab is now a GitHub-style list. You can search it by objective, label or `#id`, sort it by recently updated, newest or oldest, and switch between Open and Closed. Each row shows the issue's labels, when it was opened or closed, its tasks done and its discussion count. The issue page shows the description and each discussion as comment cards in a timeline, with short notes as compact events. Its comment box has Write and Preview tabs. A sidebar lists the issue's labels, milestone, task branches, task progress and remote. Markdown everywhere in the dashboard now uses GitHub's styling and follows the light and dark colour mode. Editing, commenting and closing work as before.
