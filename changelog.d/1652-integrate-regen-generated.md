### Fixed
- **Integrating a reviewed task no longer stops on a generated-file conflict** (GH 1652): when two tasks both rebuilt a generated file (such as the trajectory-server's `dist/` bundle), `integrate.sh` kept the base's stale copy during the rebase and then exited 2 for patch drift. It now runs `scripts/maintenance/regen-generated.sh` in the rebased worktree, amends the regenerated files into the rebased commit, and compares patches over source files only, skipping every path `.gitattributes` marks `merge=tmb-regen`. A real source conflict, source drift or a failing regen still exits 2 and leaves the branch where it was.
