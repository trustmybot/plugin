### Fixed
- **TMB now names the pre-1.1.0 hooks left in your user-wide `settings.json`** (GH 1532): `/onboard` before v1.1.0 wrote hook commands running `~/.claude/tmb-hooks/resolve-hook.sh` into `~/.claude/settings.json`, and Claude Code runs them in every project, so an old gate could deny a call v1.1.0 allows. The SessionStart inventory now adds a `Plugin:` line, and `scripts/health.sh` adds a `WARN  legacy-user-hooks` warning with the exit code unchanged. Both name the file, the count, and the line and `--hook` name of each such command, and list your other projects still on TMB below 1.1.0, which lose those hooks once they are removed. TMB only reads the file. Remove the entries by hand as `docs/reference/UPGRADE.md` describes ("Upgrading into v1.1.0 — remove leftover user-wide hooks").
