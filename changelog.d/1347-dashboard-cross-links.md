### Added
- **Every id in the dashboard is a link, and issues and commits link out to GitHub or GitLab** (GH 1347): task, issue and branch ids in the Audit feed, Runs & gates (which gains an Issue column), the issue sidebar, write errors, the issue timeline (a "task N" chip on entries tied to a task) and the task sidebar now open the matching dashboard page, all in one link style. `GH n` / `GL n` open the issue on its remote, and task commits and verification-run shas open the commit page (7 characters shown, full sha on hover), in a new tab. Remote links come from the repo's git remotes; only `https://`, `git@host:` and `ssh://git@` URLs are used, and anything else stays plain text. The list search box now follows the URL when a link or Back changes the search, instead of keeping the old text.
