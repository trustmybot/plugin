### Fixed
- **An arithmetic `$(( ))` in a heredoc body no longer joins the listed statement** (GH 2876): since GH 2635, `cat <<EOM` around `$((W=0))` was listed as `cat <<EOM $(…)`, because the body's arithmetic was read as a command substitution. Arithmetic that holds no `$( )` or backtick runs no command, so the statement is listed as `cat <<EOM` again; the body still makes `W` unknown for the statements after it, a quoted `<<'EOM'` body still leaves `W` alone, and `$((git push …);(true))` or `$((git push …) )`, which bash runs as commands, are still denied from `.claude/worktrees/`.
