### Added
- **Opt-in reviewer effort by risk tier, with an A/B** (GH 1955): `bro_atomic_close` now assigns the effort the task's code-reviewer runs at, returns it as `reviewer_effort`, and records it in one `reviewer_effort_assigned` audit row per close; the code-reviewer spawn gate and the code-reviewer `agent_runs` row both use it. With `config_set` key `reviewer_effort_tiers` set to `true`, the effort follows the risk of the change: `high` for a prompt-bearing task or a change under a `high_effort_paths` prefix, `low` when the change only touches docs or tests, `medium` otherwise. To measure it first, set `reviewer_effort_ab` to `{"label": "<name>", "target": <n>}` (for example `{"label": "gh-1955", "target": 20}`): until `target` tasks carry the label, each newly closed task is enrolled, even ids at the risk tier and odd ids at the fixed `reviewer_effort`, and a reworked task keeps its arm. With both keys unset every review runs at `reviewer_effort`, as before.
