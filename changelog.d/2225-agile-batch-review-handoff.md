### Added
- **bro hands a group of queued agile tasks to code-reviewer with `review_batch_handoff`** (GH 2225): the new bro-only tool takes a feature branch and the tasks to review together. It records the branch tip as the reviewed head and its merge-base with the repo's target branch as the base. Then it runs the close lints on the head in a temporary worktree and writes one `review_batch_handoff` audit row with the result. It returns the code-reviewer spawn, which carries `batch_handoff_id`, `feature_branch`, `head_sha`, `repo`, `repo_path` and `subagent_session_id` instead of the per-task anchors. The tool writes nothing when a task is not queued on the branch, a task's commit is not part of the head, the lints fail, or the group leaves out a queued task that changed a file the group also changed; that last refusal lists the tasks and files involved. The code-reviewer spawn gates accept either anchor set. Before the spawn, they check that the branch tip is still the handed-off head, that the recorded lint run passed under the head's current close-lints config, and that every task is still queued. `review_batch_record` now requires `batch_handoff_id` and refuses a verdict whose tasks, head or branch differ from that handoff's.
