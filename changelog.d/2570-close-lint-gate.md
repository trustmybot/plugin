### Added
- **swe's close now runs the repo's close lints, and so does `integrate`** (GH 2570): once `verification[]` passes, the swe close gate runs each lint the repo lists in `.config/tmb/close-lints.json` (`{"version":1,"lints":[{"name","command"}],"fingerprint_inputs":[<globs>]}`), from the worktree, followed by the built-in missing-changelog and stale-doc-reference checks. The whole run is recorded in `lint_runs`. If any lint fails, the close is blocked with each failing lint, its exit code and its last 15 output lines. The lints share whatever time `verification[]` left, and a lint still running when that runs out is recorded as exit 124. A clean run on the same commit, base and fingerprint is reused instead of run again. A repo without the file gets the two built-in checks only, and a malformed file blocks the close. `cli.js integrate` runs the same lints on the rebased commit and exits 1 without moving the branch if one fails. The plugin's own close-lints.json runs the L1 lint tier.

### Fixed
- **`swe-edit-lint` globs match dot paths** (GH 2570): `**/*` in `.config/tmb/edit-lint.json` now matches `.github/x.yml` and other dot paths, so the plugin's edit-lint.json needs one glob instead of three.
