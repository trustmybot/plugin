### Added
- **World model symbol cards list a function's parameters and return type** (GH 3176): `world_model_symbol` now returns `params` and `returns` for TypeScript and JavaScript functions and methods. Each parameter carries its name, declared type, whether it is optional, and its default value when it has one. JavaScript parameters have no declared type, so their type is null. Classes, tables and other non-function symbols return null for both fields, and the existing `signature` string is unchanged. Upgrading to schema v74 adds a `params_json` column to `wm_symbols` and reserves four edge kinds that nothing writes yet: `references_value`, `mentions_path`, `doc_link` and `generated_from`. The next scan re-parses every file to fill in the parameters.
