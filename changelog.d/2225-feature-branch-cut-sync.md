### Added
- **`cli.js feature-branch cut|sync <name>` cuts and syncs an agile feature branch** (GH 2225): `cut` creates the branch at `origin/<target>`, after one bounded fetch, or at the local target when there is no origin, and prints its SHA. `sync` merges `origin/<target>` into the feature branch with a merge commit made in a temporary worktree, so every commit already on the branch stays on it, and prints the new tip; a branch that already contains the target is left as it is. The target is the repo's `target_branch`, else the remote default. The repo is `--repo <name>`, else the registered repo the command runs in, else the only registered one. Exit 4 refuses the target branch, a protected branch, an invalid name, a `cut` of a branch that already exists, and a `sync` of a missing branch or one checked out in a worktree; a merge conflict exits 2 and lists the conflicting paths. In every refusal no branch is created or moved. Neither subcommand pushes or writes the trajectory DB.
