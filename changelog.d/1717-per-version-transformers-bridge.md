### Fixed
- **Each installed plugin version loads its own pinned @huggingface/transformers** (GH 1717): every version's `node_modules/@huggingface/transformers` symlink pointed at the shared `$CLAUDE_PLUGIN_DATA/deps/current`, so two installed versions pinning different transformers versions switched `current` under each other and one loaded the other's package. The SessionStart hook now bridges each version to its own `deps/<version>-<platform>-<arch>/` install and re-points an existing bridge to `current` on the next session start. Cleanup of an older version's hook-installed `node_modules` bridges it to the install its own pin names, or leaves it for its own hook to install, and an install still in use by `current` or by a version's bridge is never removed. `deps/current` is still kept up to date for bridges written by earlier releases.
