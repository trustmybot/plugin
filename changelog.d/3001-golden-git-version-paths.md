### Fixed
- **The hook-golden parity suites pass with any git version and any required schema number** (GH 3001): the sandbox trees they compare listed the `.git/hooks/*.sample` files and the `.git/worktrees/<name>/refs/` dirs that only some git versions create, so a machine whose git ships a different set (Apple git 2.39 has no `sendemail-validate.sample`) failed every task-close and agent-spawn case. Both the stored and the live tree now drop those paths before comparing. The session-scans comparison also replaces the required number in a `schema vN < vM` banner with a placeholder on both sides, since that number is the highest schema version any data contract needs and moves with each contract bump, while the stored number N and the banner's shape are still compared. The recordings themselves stay byte-identical. No production code changed.
