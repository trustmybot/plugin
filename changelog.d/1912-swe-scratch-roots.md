### Fixed
- **swe can write scratch files to its session scratchpad and `$TMPDIR`** (GH 1912): `swe-boundary` denied an swe's Edit/Write to the scratchpad Claude Code gives it (`/tmp/claude-<uid>/<project>/<session_id>/scratchpad/`) as outside the worktree. It now allows that dir when it is a real directory you own and it belongs to the calling session. Other sessions' scratchpads and symlinked ones are still denied, and the deny message now names the scratchpad to use. `containment-guard` judged a sandboxed Bash write to `$TMPDIR/…` as unresolvable, because the hook's own env has no `TMPDIR`. It now judges the write under `/tmp/claude-<uid>`, the `TMPDIR` the sandbox runs the command with. A call marked `dangerouslyDisableSandbox` is judged as before.
