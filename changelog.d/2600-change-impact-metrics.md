### Added
- **Every change gets before/after statistics on the agent metrics** (GH 2600): the new read-only `change_impact` tool takes a change `{source, id}` and compares the runs before it with the runs after it, within 14 days of the change and at most 200 runs a side. Two sources work in any project, with no repo, branch, milestone or label built in. `plugin_version` treats each installed TMB version as a change, comparing its runs with the previous version's; when runs carry dev builds, it finds the registered repo whose history holds those builds and gives one change per merged PR instead, with older unversioned runs placed by time and counted as estimated. `agent_surface` treats each commit on a registered repo's base branch that touches `CLAUDE.md`, `.claude/agents/`, `.claude/skills/` or `.claude/settings*.json` as a change, splitting runs at the commit time; the `change_impact_agent_surface` config key replaces those paths, and `<repo>:<glob>` scopes one to a repo. A commit's id is its PR or merge-request number when the repo has a remote, else its short SHA. It covers swe rework ratio, tokens per task, reworks per task, review fail rate, first verification pass rate, hook-block tokens per swe run and bro tokens per session. For each it reports both sides' count, median and mean, the ratio of medians with a 95% confidence interval, a Mann-Whitney p-value corrected across the metrics, and a verdict: improved, regressed, no change, or not enough data under 20 runs a side. `measured_with` names the other changes no run separates from this one, so their effects cannot be told apart. Without a change it lists the last 20 changes, optionally of one source. The same numbers come from `node --experimental-sqlite dist/change-impact/cli.js --db <path> --source <S> --id <I>` (or `--list`).
