### Fixed
- **bro's token usage stays recorded on long sessions** (GH 2699): the Stop hook that keeps the session's bro row in `agent_runs` up to date re-read the whole session transcript on every turn, so on a long session (a transcript of a few hundred MB) it ran past its time budget every time and the row stopped updating. It now reads only what the transcript gained since the previous turn, keeping its progress in a small cache file next to the trajectory DB (`bro-turn-usage/<session_id>.json`), and the row holds the same totals a full read would. When that cache is missing, damaged or no longer matches the transcript, the hook reads the transcript in full as before.
