### Changed
- **L5 and L6 run only on the TypeScript runners** (GH 1692, wave 2 part 2c). release-gate's L6 chain step runs `node --experimental-strip-types --experimental-sqlite tests/l5-l6/run-l6-chain.ts` with `--fresh` or `--from <step>` as before, the release canary Dockerfile runs `tests/l5-l6/run-l5.ts` the same way, and the docs name the TS commands. `run-l5.sh`, `run-l6-chain.sh`, the `tests/l5-l6/lib/*.sh` libs (`flow-helpers`, `l6-chain-helpers`, `sandbox`, `smoke-helpers`, `timeout-shim`) and `flow-helpers.test.sh` are gone, and `tests/run-all.sh` no longer runs that suite. The sandbox isolation cases (gh and glab fail with the sandbox message, an https git push is blocked, teardown restores PATH and HOME) moved from `mcp/trajectory-server/src/test/sandbox-isolation-l3.test.ts` into `tests/l5-l6/lib/sandbox.test.ts`, which drives `sandbox.ts`. The no-home-writes lint now scans the non-test `.ts` files in `tests/l5-l6/` and `tests/l5-l6/lib/` in place of the deleted `.sh` files.
