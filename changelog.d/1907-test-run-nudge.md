### Changed
- **swe is nudged to run tests through `test-run.js`** (GH 1907): when swe runs a raw test command (`node --test`, `bun test`, `npm test`, `vitest`, `jest`, `pytest`, or a shell script under `test/` or `tests/` or named `*.test.sh`), a new advisory hook adds one line telling it to rerun the command as `node "${CLAUDE_PLUGIN_ROOT}/mcp/trajectory-server/dist/test-run.js" -- <argv...>`, which prints only the pass/fail summary and each failure and keeps the full log on disk, so a test run no longer fills swe's context with the whole suite output. The command still runs as typed; the hook never blocks it. Commands that already go through `test-run.js`, and every agent other than swe, get no line. `TMB_SKIP_TEST_RUN_NUDGE=1` turns it off.
