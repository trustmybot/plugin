### Fixed
- **A rebase keeps the review pass only when the base missed the diff** (GH 3108): `cli.js integrate` carried the code-reviewer pass to every verified rebase, even when the base commits it moved over changed the task's files or the files that import or call them. It now carries the pass only when the base touched none of the task's files or their world-model dependents. Otherwise it still rebases, verifies and moves the branch, but exits 5 and names the overlapping paths, and the push gate denies the new commit until code-reviewer passes it again. A world model it cannot read counts as an overlap ("world model unavailable").
