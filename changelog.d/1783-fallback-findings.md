### Fixed
- **A fail verdict recorded without the MCP server now leaves findings the close gate probes** (GH 1783): `validation-record-fallback.sh`, the pr-reviewer's path when `validation_record` is unavailable, wrote the verdict but no `review_findings` rows, so the gate had nothing to re-run on the next close. It now takes the findings as a sixth JSON argument and records them like `validation_record` does. A fail needs at least one finding, a pass refuses them, and a malformed entry is refused with nothing written. Each finding gets an id `F<task>-<n>` that is never reused, and re-recording an attempt replaces only that attempt's open findings. The hooks README now documents the gate's finding probes, and the ERD lists every writer of `review_findings`.
