### Added
- **A Push Gate board on the dashboard's Runs tab** (GH 1347): one row per branch that has open tasks or work in the last 14 days, labelled ready, blocked or pending. Each task in the row links to its task page and shows its status, its latest verification run (pass, fail, timed out, or stale when it ran on another commit), its latest review verdict and its open blocking findings. A branch is blocked when any task failed its latest verification or review or has an open blocking finding, and ready when every open task passed verification on its own commit and passed review. Before this, the Runs tab only listed recent runs and verdicts, so working out what still stopped a branch from pushing meant reading them one by one. The data is also served at `GET /api/gate-board`.
