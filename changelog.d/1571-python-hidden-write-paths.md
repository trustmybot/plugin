### Fixed
- **An inline python program that can hide a write is now denied instead of slipping past the containment guard** (GH 1571): referencing `runpy`, `code`, `codeop`, `doctest`, `pickle`, `marshal`, `shelve`, `importlib`, `pydoc`, `types`, `inspect` or `sys.modules`, `breakpoint`, a `__globals__` / `__class__` / `__subclasses__`-style attribute, a `getattr` with a computed name, a subscript of `globals()` / `vars()`, a builtin such as `open` held as a value (`o = open`), a `timeit` / `cProfile` / `pdb` `.main`, or a hex / unicode / octal escape in a string literal makes the program unresolvable, so its variable writes and process calls are denied. `python -m timeit` / `cProfile` / `profile` / `trace` / `pdb` / `runpy` / `code` / `doctest` / `pydoc` / `pickle` / `py_compile` / `compileall` is denied whatever its arguments; `python -m json.tool`, `python -m pytest` and ordinary programs are judged as before.
