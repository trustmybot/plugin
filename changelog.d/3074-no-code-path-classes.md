### Added
- **A repo can now mark which of its files are docs and which are prompts** (GH 3074): every change was treated as code, so even a README fix needed the full code pipeline. A repo can commit `.config/tmb/path-classes.json` listing its docs and prompt globs (plus the rubric files prompt reviews use); a change is classed docs, prompts, code or mixed from it, and a path no glob covers stays code, as does every path when the file is absent. `/onboard` gains a per-repo path-classes question that proposes globs from the docs and prompt files it finds on the PR target and writes the file uncommitted. Later releases use the classes to let bro handle docs and prompt changes directly.
