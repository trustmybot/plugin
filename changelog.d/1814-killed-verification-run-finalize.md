### Fixed
- **A killed verification run no longer stays unfinished forever** (GH 1814): stopping `integrate.sh` mid-verification left its recorded run open (`finished_at` empty), so `trajectory_doctor` kept warning under `no_unfinished_verification_runs`. `integrate.sh` now finishes an open run when it exits: exit 130 on Ctrl-C, 143 on TERM, or the failure code it exits with. A run it has already finished is left as it is. For a run that cannot be finished at all, such as one whose process got SIGKILL, the next verification run of any task finishes it as exit 137 once it is more than 60 s past its own budget. Runs still within their budget are left alone, and a run finished this way never counts as passing.
