### Changed
- **The last two shell hook libs are now thin shims over TypeScript** (GH 1692, the runtime hook TypeScript port): `scripts/hooks/lib/query-task.sh` keeps only `tmb_db_path` and `resolve-install.sh` only `_tmb_install_plugin_name`. Each runs the new `dist/cli.js hook-lib` subcommand (`db-path` prints `dbPath`, and exits 1 with no output when no DB resolves; `install-plugin-name` prints `installPluginName`), finding the plugin root from the shim's own location, not `CLAUDE_PLUGIN_ROOT`. `src/test/hook-lib-shims.test.ts` checks both shims against their TypeScript source. The docs, comments and lint allowlist rows that named the removed shell functions now name the TypeScript functions that replaced them.
