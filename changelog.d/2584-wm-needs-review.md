### Added
- **World-model answers list what bro should review** (GH 2584): `world_model_get`, `world_model_search` and `world_model_symbol` carry a `needs_review` key when there is something to check. It lists the concepts a reindex marked `suspect` or `broken`, which stay listed until they are re-verified, and the dirs whose README text changed, which stay listed until one answer has reached bro. Each list shows at most 20 entries, with `needs_review_truncated` giving the totals. The `freshness` block's `needs_review_count`, on the server and in the dashboard, now counts both kinds, and each `wm_reindex` audit row records `concepts_flagged`. Schema v64 adds `wm_directories.readme_review_pending`.
