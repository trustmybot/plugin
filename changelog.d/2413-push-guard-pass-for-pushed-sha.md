### Fixed
- **git-push-guard admits a push only on a review of the pushed commit** (GH 2413): the guard let a task commit through on any past `pass` verdict for the task, so a commit added after the review still pushed. It now uses the shared review predicate: a pass counts only when it was recorded at or after bro's first `bro_verification_pass` of the task's current `commit_sha`. A task with no such anchor is unsigned, and a rebase of a task whose pass predates its current commit's anchor is denied as "the task has no passing review".
