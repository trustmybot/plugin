### Added
- **A TypeScript write-path analyzer for Bash commands, checked against the bash one** (GH 1692): `mcp/trajectory-server/src/hooks/cmd-analysis/` reads the files a Bash command writes from a tree-sitter-bash parse, giving the same lines as `tmb_cmd_write_paths` in `cmd-analysis.sh` over a 1319-command corpus (12 recorded cases where it is stricter, such as a command bash cannot parse). No gate uses it yet. Interpreter one-liners, find/fd/xargs exec and loop listers were ported in a follow-up task (task 74), and a command with a parse error prints only `UNRESOLVED:$(parse):…`, so it never returns a partial list. A hook gate may now also return its result as a Promise. Cold-process wall time, p50 of 10 runs on macOS with node 24.15 (`node -e 0` takes 25 ms): `ls -la` takes 48 ms through `node -e` importing `dist/hooks/cmd-analysis/index.js` and 25 ms through `bash -c 'source cmd-analysis.sh; tmb_cmd_write_paths …'`; `echo hi > out.txt` takes 50 ms and 29 ms; a `git commit -F - <<'EOF'` heredoc takes 49 ms and 34 ms.
