### Changed
- **Plugin remedies are scoped CLI commands and a full restart, never in-session commands** (GH 1730): every install, update, enable, disable and uninstall instruction TMB gives is now a `claude plugin … --scope <s>` command run from the project root, and every remedy that said `/reload-plugins` or reconnecting through `/mcp` now says to fully quit and relaunch Claude Code, since a plugin change applies only after a restart and `/plugin` does not work in Claude Desktop. The duplicate-copies warning (SessionStart banner, the prescan's `Plugin:` line, `scripts/health.sh`) prints `claude plugin disable <plugin>@<marketplace> --scope <scope>` for each enabled copy; the version-skew line, `health.sh` (including the hook-cache-drift check), the deferred-tools drift warning, the `single_tmb_plugin_enabled` doctor contract, `tmb_recovery`, `/agent-create`, the rc README template and the install and upgrade docs follow suit. A new lint, `tests/l1-lint/no-in-session-plugin-commands.sh`, keeps the slash forms out, and `cli-config-scope.sh` accepts a call shown to the Human when its line carries a `# cli-config-scope: printed` comment.
