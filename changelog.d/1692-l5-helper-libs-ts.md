### Changed
- The L5/L6 helper libs have TypeScript ports (GH 1692, wave 2 part 1). `tests/l5-l6/lib/{flow-helpers,l6-chain-helpers,sandbox,smoke-helpers,timeout}.ts` export one camelCase function per function of `flow-helpers.sh`, `l6-chain-helpers.sh`, `sandbox.sh`, `smoke-helpers.sh` and `timeout-shim.sh`, with the same paths, files, env and exit codes. A function that exported into its caller's shell (the sandbox init, `l6c_isolate_home`, the smoke DB isolation) now takes a base env and returns the new one, and nothing writes `process.env`; `runWithTimeout` replaces the timeout/gtimeout/perl fallbacks with spawnSync's timeout (SIGKILL, status 124). The plugin name comes from the built `dist/hooks/lib/install.js`. Each module has a node:test suite, run as one L3 step of `tests/run-all.sh`; `flow-helpers.test.ts` carries every case of `flow-helpers.test.sh` and drives the hooks through the built `dist/hooks.js`. The runners still source the `.sh` libs until wave 2 part 2.
