### Changed
- The L5 runner has a TypeScript port (GH 1692, wave 2 part 2a). `node --experimental-strip-types --experimental-sqlite tests/l5-l6/run-l5.ts [filter]` does what `run-l5.sh` does on the TypeScript helper libs: the token and PATH checks with the same messages, the pre-flight smoke, leaf-row discovery one and two levels under `rows/`, the name filter, the per-row seed, `setup-l5.sh`, sandboxed step, scoring and trajectory doctor, and the `L5: N passed, M failed` summary. The per-row env (`FLOW_NAME`, `RUN_ID`, the sandbox) is an object and nothing writes `process.env`; a row whose step throws counts as failed and its project is still removed. jq is no longer required: the runner checks only for claude and sqlite3. `run-l5.test.ts` drives `main` against fixture rows with a stub claude, as an L3 step of `tests/run-all.sh`. `run-l5.sh` stays until part 2c switches its callers. The flow-helpers suite no longer inherits a caller's `FLOW_NAME` and `RUN_ID`, so it no longer writes run logs under the checkout's `.claude/tmb/l5-trajectories/`.
