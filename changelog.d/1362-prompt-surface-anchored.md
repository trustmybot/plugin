### Fixed
- **A project's own `src/agents/` or `docs/templates/` markdown is no longer denied as TMB prompt surface** (GH 1362): `tmb_is_prompt_surface_path` matched `agents/`, `skills/`, `commands/`, `templates/` and `rules/` at any depth, so the swe-boundary and no-source-edit-from-main guards refused edits to unrelated user files. It now anchors on the repo root (the enclosing task worktree, else the main git root): only a root-level `agents/`, `skills/`, `commands/`, `templates/`, `rules/` or `.claude/{agents,skills,commands,rules}/` counts, while `CLAUDE.md`, `CODEX.md`, `CURSOR.md` and `GEMINI.md` still match anywhere and a path outside any repo keeps the old match.
