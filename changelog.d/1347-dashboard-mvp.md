### Added
- **A local, read-only dashboard for your issues, tasks, agent runs and gates** (GH 1347): `scripts/dashboard.sh` starts a small server on `127.0.0.1` (port 7477, or `TMB_DASHBOARD_PORT`) over the project's trajectory DB and prints its URL. The page shows overview cards, an issues table with each issue's tasks and discussion, a tasks table, agent runs with review verdicts and verification runs, and the audit feed, and refreshes itself within two seconds of any change to the DB. It only reads the DB, needs no extra runtime dependencies, and is reachable only from your own machine.
