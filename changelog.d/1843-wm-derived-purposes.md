### Changed
- **Nearly every file in the world model now has a purpose** (GH 1843): files with no header comment used to get an empty purpose, so bro's map showed bare names for most code and data. The scan now derives a purpose from the symbol index for code files (`exports: …`, top-level definitions, or `tests for <subject>: …` with the first test titles, source `symbols`) and from the file's shape for data files (JSON/YAML name, description, schema or keys; `.txt` and `changelog.d/` roles; a heading-less Markdown file's first line, source `structural`). Neither ever overrides a header, `.tsx` headers are now read, and files left without a purpose are re-checked on the next scan.
