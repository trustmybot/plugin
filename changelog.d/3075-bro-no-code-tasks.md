### Added
- **bro edits docs and prompts itself, in a no-code task's worktree** (GH 3075): `task_provision` takes an optional `task.no_code_class` (`docs` or `prompts`), stored on the task and kept by `task_retry`. bro may Write or Edit a file only inside the worktree of a running task that has a class, and only on a path that `.config/tmb/path-classes.json` classes as docs or prompts. The classes are read at the task's base commit, so the task cannot widen its own limits. Code paths, tasks without a class, and edits in the main checkout are refused, and the refusal names swe. This includes Markdown and docs files in the main checkout, which bro could edit before. When bro closes such a task, the same checks run as when swe closes a task: its verification commands and close lints, recorded for the commit. Every changed path must also be docs or prompts; a code or mixed change is refused, with its code paths listed. swe, consultants, and closes of tasks without a class behave as before.
