### Fixed
- **Semantic search works again after a fresh install or update** (GH 1669): since the kuzu install hook was removed, nothing installed the MCP server's `@huggingface/transformers`, so every session started with embeddings degraded and search fell back to FTS. A new SessionStart hook, `ensure-mcp-deps-installed.sh`, checks whether the package resolves and, when it does not, installs the server's production dependencies in the background with `bun` (or `npm`) and no lifecycle scripts, so the plugin's own build never runs in the plugin cache. Embeddings go live on the next Claude Code restart. With neither `bun` nor `npm` on PATH, the session start note names the command to run by hand. Set `TMB_SKIP_MCP_DEPS_INSTALL=1` to turn the hook off.
