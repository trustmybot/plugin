### Fixed
- **`cli.js feature-merge` lints a rebased task and re-queues only unreviewed work** (GH 2225): when it rebases a closed agile task onto the feature branch, it now runs the close lints on the rebased commit after `verification[]` and records them, as `cli.js integrate` does; a failing lint exits 1 and leaves the feature branch where it was. It writes a `review_queued` row for the rebased commit only when the task has no passing review, so reviewed work is not queued again. A no-code task with an empty `verification[]` now fast-forwards instead of exiting 4; a code task with none still exits 4.
