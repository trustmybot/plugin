### Added
- **The world model knows which code reads each `plugin_config` key** (GH 2325): the symbol index now records a `reads_config` edge from each TypeScript or shell symbol whose SQL selects from `plugin_config` to every key it reads. That covers a literal key, a `?` placeholder bound to a string or a same-file constant, and an `IN (...)` list. Keys built at run time are skipped, and so are writes. `world_model_symbol` cards gain `reads_config`, and `world_model_symbol(config_key='x')` lists the readers of key `x`. The trajectory DB moves to schema v60 on the next session start, and every file is re-parsed once.
