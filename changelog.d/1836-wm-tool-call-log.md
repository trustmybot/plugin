### Added
- **World-model tool calls are now logged, so you can measure how often the map answers** (GH 1836): each call to `world_model_get`, `world_model_search`, `world_model_symbol`, `world_model_concepts`, `world_model_concept_get` and `world_model_concept_upsert` writes one `wm_tool_called` audit row with the tool, the calling agent, its task when known, the result count, whether it came back empty and the latency. Agents cannot write this event through `audit_append`, and a failed log never changes the tool's answer. `docs/architecture/WORLD_MODEL.md` ("Measuring WM use") has the SQL for calls and empty-result rate per tool and calls per task.
