### Changed
- **A swe's task brief is a short core by default, with the rest loaded on demand** (GH 1743): `task_brief` takes an optional `section` (`core`, `verification`, `scope`, `history` or `all`). A swe now gets `core` unless it asks for more: the task row, spec, files, open findings, completion report and spawn note, plus a `sections` map saying when to load the verification commands and last gate run, the scope and world-model summary, or the discussion history. Bro, pr-reviewer and consultants still get the whole brief by default, and the close gate still runs every verification command. An unknown `section` is refused with the list of valid values.
