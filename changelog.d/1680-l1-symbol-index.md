### Added
- **The world model now knows the functions, classes, shell functions and SQL tables in your code, and who calls them** (GH 1680): `/scan` parses TypeScript, JavaScript and shell files with tree-sitter (bundled with the plugin, nothing to install) and reads SQL table, index and trigger definitions. It records each top-level definition with its signature and doc comment, plus the calls, imports and table reads and writes between them. `world_model_search` now returns `kind: 'symbol'` hits alongside directories and files, and ranks a file higher when both its name and its code match; build output under `dist/` and source maps no longer appear as file hits, and tests and changelog fragments rank lower. The new `world_model_symbol` tool shows one symbol's callers, callees, imports, tables and tests, and says when some callers were matched by name, so the list may be incomplete. Only changed files are re-parsed on a rescan. Schema v44 adds the symbol tables; they fill in on the next `/scan`.
