### Fixed
- **Hook tests no longer time themselves, so they stop failing on a busy machine, and a lint keeps elapsed-time checks out of the tests** (GH 1677): the dispatcher and DB-write tests checked elapsed time against fixed bounds: a slow gate cut off in under 9 s, a locked write giving up within 3 s, three locked writes inside 3–4.5 s, a deny no slower than an allow plus 300 ms, and a gate chain within twice one gate plus 100 ms. A loaded runner could fail any of these even when nothing was wrong. The tests now check what happened instead: the dispatcher denies before the slow gate finishes, a locked write fails with a lock error while the lock is still held, later writes fail fast once the run budget is spent, and a deny's audit row is written only after the hook has returned. The chain-latency check is dropped because it measured nothing but speed. The new `tests/l1-lint/no-wall-clock-asserts.sh` fails any shell test that compares a `$SECONDS` or `date +%s` difference to a bound, and any TypeScript or JavaScript test that does the same with `Date.now()` or `performance.now()`, unless the line is allowlisted with a reason. That keeps the GH 1645 cleanup from coming back.
