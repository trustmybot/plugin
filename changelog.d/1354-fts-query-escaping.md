### Fixed
- **`discussion_search` and `audit_search` no longer fail on hyphens, dots and colons** (GH 1354): the query was bound raw to FTS5 `MATCH`, so `dir-level world model` raised `no such column: level` and `AGENTS.md` raised `fts5: syntax error`. Every term is now double-quoted before it reaches `MATCH` (a phrase you already quoted stays one term), so these queries match as plain words in keyword and hybrid modes. A query FTS5 still rejects returns `fts_query_invalid: <message>` instead of a raw SQLite error. Phrase-prefix (`term*`) and boolean operators in the query text are no longer interpreted.
