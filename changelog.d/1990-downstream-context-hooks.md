### Added
- **swe and code-reviewer can walk a symbol's impact** (GH 1990): both agents now carry `world_model_symbol`, `world_model_search` and `world_model_get`. Before swe reshapes a symbol's signature, return value or written table, it runs `world_model_symbol(..., impact: 2)` and fixes or reports each caller and table reader. The code-reviewer runs the same walk for each symbol the diff renamed or reshaped, and a caller the diff left broken is a finding.
- **Direct-downstream context hooks, behind an opt-in A/B** (GH 1990): with `plugin_config.downstream_context_ab` set to `{label, target, tools_shipped_at}`, tasks enroll as they reach the hooks, half in an `on` arm. On an `on` task, `swe-downstream-context` tells swe, at its first edit of an indexed file, which code calls into that file or reads the tables it writes. `reviewer-downstream-context` tells the code-reviewer, at its start, which symbols the diff changed and what calls or reads them. Both show up to 30 refs and about 2000 characters, never block, and stay silent when the key is unset. `src/downstream-context-ab-report.ts` compares a pre-tools baseline, the `off` arm and the `on` arm on tokens, first-pass rate, caller bugs and world-model calls per run.
