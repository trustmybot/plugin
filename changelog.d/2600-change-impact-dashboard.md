### Added
- **Change impact in the dashboard** (GH 2600): Insights has a new Change impact section, read-only like the rest of the dashboard. It lists the last 20 changes from every source with runs, newest first, with each change's source, time, kind, its significant metric shifts (for example `bro tokens per session improved`, or `no significant shift`) and how many other changes were measured together with it. A Source select, built from the sources that have changes, narrows the list. Clicking a change shows, for each metric, the run count and median before and after, the ratio of medians with its 95% confidence interval, the corrected p-value and the verdict, plus the changes measured with it. Change impact sets its own 14-day windows, so the Period and filters do not apply to it. The numbers come from `GET /api/insights/change-impact` (`source`, `limit` up to 100; or `source` and `id` for one change), the same computation as the `change_impact` tool.
