### Fixed
- **Failed and reaped swe runs no longer fail the `swe_runs_metered` doctor check** (GH 1673): a swe or pr-reviewer run closed without any token usage (a task moved to failed or escalated, an issue-close cascade, `task_recover`'s stale and terminal-task sweeps, a merge, an orphaned or refused spawn, a SubagentStop whose transcript holds no usage) was left with no `usage_source`, so `trajectory_doctor` reported it as an unmetered run. Every path that closes a run now applies one rule: a run with no tokens and no source is marked `unmeasured`. A run that carries tokens or a source keeps them, and a later stop with no usage no longer zeroes the tokens an earlier stop recorded.
