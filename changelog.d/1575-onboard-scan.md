### Added
- **`/onboard` looks at every repo before it recommends a branching model** (GH 1575): `onboard_state_get` now returns `scan`, one entry per registered repo with offline git evidence (long-lived branches, `origin/HEAD`, first-parent merge counts on each candidate branch, CI files, `CONTRIBUTING.md`) and a recommendation with a confidence level and short evidence lines, plus a workspace summary that says whether every repo points the same way. A repo whose merges land on `dev` is no longer told to use GitHub Flow. The result is stored in the new `repos.onboard_scan` column (schema v40); no `gh` or `glab` call is made.
