### Fixed
- **swe can write into `$(mktemp -d)` and `${TMPDIR:-/tmp}` in a sandboxed Bash call** (GH 1912): the write-path analyzer now resolves a command substitution that is exactly an allowlisted mktemp call (flags only `-d`, `-q`, `-t <prefix>`, at most one template) to the path mktemp prints, and `${NAME:-def}`, `${NAME:=def}`, `${NAME-def}` and `${NAME=def}` for PWD, OLDPWD, HOME, TMPDIR, CLAUDE_PROJECT_DIR and TMB_MODEL_CACHE_DIR read the run env first, as bash does. containment-guard judges the write where it lands, so `T=$(mktemp -d); echo x > "$T/f"` passes under `/tmp/claude-<uid>`; any other substitution, a template outside the scratch roots, or a no-template mktemp marked dangerouslyDisableSandbox with no hook TMPDIR is still denied.
