### Added
- **`review_queue` lists the agile tasks still waiting for code review** (GH 2225): a new bro-only, read-only tool returns the tasks closed under `workflow_mode` `agile` that have no passing review, bro-written waiver or allowed bypass, the same tasks `trajectory_doctor`'s `agile_review_queued` counts. It reads each task's own recorded mode, so the tasks stay queued after the setting goes back to `truest`. Tasks whose declared files overlap are grouped, so one reviewer pass can cover each group, and each group carries a `base`..`head` commit range. Optional `repo` narrows it to one repo, and `grace_hours` (default 0) leaves out recent closes. It runs no git.
