### Added
- **Opt-in A/B of swe effort, with a per-arm report** (GH 1745): switch it on with `config_set` key `swe_effort_ab`, value `{"label": "<name>", "target": <n>}` (for example `{"label": "gh-1745", "target": 20}`). Until `target` tasks carry the label, every new task from `task_provision` or `task_create_batch` that would run at the default effort or an explicit `medium` runs at its task id's arm instead: even ids at `high`, odd ids at `medium`. The response shows `effort_reason: "ab_arm"`, and each enrolled task gets one `effort_ab_enrolled` audit row. Reworks (`task_reopen`, `task_retry`), explicit `high` or `low`, prompt-bearing tasks and `high_effort_paths` tasks are never enrolled. With the key unset, effort works as before. `node scripts/maintenance/effort-ab-report.ts --label <name>` (add `--db <path>` to pick a DB) opens the DB read-only and prints, for each arm, the task count and the median and mean of wall-clock, swe tool calls, swe cache-read tokens, review FAILs and time to merge.
