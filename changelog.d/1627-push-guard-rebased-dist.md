### Fixed
- **A rebased task commit whose built `dist` was regenerated no longer slips past the push gate unreviewed** (GH 1627): the push gate recognised a rebased task commit only by its exact patch-id, so a rebase that also rebuilt `mcp/*/dist` or `dashboard/dist` looked like untracked work and was pushed without review or verification. The gate now also compares commits with those generated paths left out; such a rebase is denied, naming the task, until the gate (`integrate.sh`) records a passing verification run for the rebased commit. Commits that change only generated `dist` files and belong to no task are still pushed as before.
