### Changed
- **rc installs now carry only the runtime payload, and every stable tag builds one too** (GH 1699): the rc channel served the full tag tree, tests and TypeScript sources included. A new `release-payload` workflow builds the same runtime-only payload as `dev-build` from each `vX.Y.Z` and `vX.Y.Z-rc.N` tag and pushes it as `payload/<tag>`; a stable tag also moves the `stable-build` branch to it. `scripts/publish-rc-channel.sh` (and `release.sh` step 6 through it) now waits for `payload/<tag>` on origin, then pins the rc catalog to it, so `tmb@trustmybot-rc` installs the slim build. The stable catalog moves to `stable-build` with a manual repin at release (GH 1888).
