### Fixed
- **World-model summaries read as prose, and section banners no longer pose as symbol docs** (GH 1834): a directory's README summary kept raw HTML, so the plugin root summary spent its 1024 bytes on the hero `<p><img>` block. Summaries now drop HTML tags and comments (keeping their text), images, badge rows and leading blocks with no prose. A `# -----` comment banner above a function, or a comment set off from it by a blank line, became that function's doc. Now a symbol takes a doc only from the comment block directly above it, and a banner block gives it none. The extractor version is bumped, so the next scan re-parses every file once and replaces the stored banner docs.
