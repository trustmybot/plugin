### Added
- **Edit model prices and issue label lists from the dashboard** (GH 1347): a new Settings tab edits `model_prices` (one row per model with its input, output, cache read and cache write price) and the area, classification and priority label lists. Each save goes through the same `config_set` handler bro uses and adds an audit row marked `actor: human`, `source: dashboard`. A value that changed since you loaded it is refused, with a prompt to reload, and a bad value is refused with the field it fails on. Policy settings, such as `onboarded` or `sandbox_enforcement`, cannot be changed here; they still change only through `/onboard`.
