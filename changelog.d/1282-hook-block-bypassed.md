### Added
- **A write that works around a denied Bash command is recorded** (GH 1282): when a `PreToolUse` Bash gate denies a command that writes a file and the same session then rewrites that file with Edit, Write, MultiEdit or NotebookEdit, `swe-boundary.sh` still allows the write but appends a `hook_block_bypassed` audit row (`tool`, `path`, `denied_gate`, `denied_at`, `session_id`, `task_id`) and tells the swe that a hook block is a hard stop to report to bro. `dispatch.sh` keeps the denied write paths under `<state>/locks/boundary-denies/<session_id>/` for `TMB_BYPASS_WINDOW_MIN` minutes (default 10).
