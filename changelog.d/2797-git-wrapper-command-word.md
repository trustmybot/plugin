### Fixed
- **git gates see git behind wrappers and paths** (GH 2797): git-push-guard, git-guards and the other gates on the shared git parser read a statement as git only when its first word was literally `git`, so `/usr/bin/git push`, `xargs git push`, `doas git push` and the like skipped them. git is now found by its basename and behind a fixed wrapper table (`env`, `command`, `exec`, `nice`, `nohup`, `time`, `sudo`, `doas`, `xargs`, `timeout`, `stdbuf`, `ionice`, `chrt`, `taskset`, `setsid`), chained; a wrapper option the table does not know, a non-literal word it must skip, or an `xargs git` with no subcommand leaves the subcommand unknown, and git-push-guard denies it.
