### Fixed
- **A perl or ruby sleep no longer blocks the command it sits in** (GH 1887): the write-path guard read `perl -e 'select(undef,undef,undef,0.25)'`, `perl -e 'sleep 1'` and `ruby -e 'sleep 0.5'` as unproven inline programs and denied the whole command, so a plain wait before `some-cmd > out.jsonl 2> err.txt` could not run. `sleep` now proves as a no-write call in perl and ruby, and perl's `select` proves only in the 4-argument sleep form `select(undef,undef,undef,<number or $scalar>)`; the command's own redirects are judged as before. Any other `select` (such as `select(STDERR)`, which redirects default output), a bare `undef`, or a call nested in the wait argument is still denied.
