### Fixed
- **`world_model_symbol` no longer binds a member call to an unrelated method that shares its name** (GH 1838): a call such as `segments.join('/')` or `/re/.test(s)` used to resolve to the one repo method named `join` or `test` (`WritePaths.join`, `LocaleGrep.test`), whatever the receiver was. A member call now resolves only when its receiver's class is known from the same file (`new C()`, a `x: C` annotation on a variable or parameter, or a class field or constructor parameter property for `this.x`) or the receiver is the class itself (`C.m()`), and only to the method `C.m`; any other member call stays unresolved. Calls on untyped locals, call results and inherited methods are no longer bound. The extractor version moves to 10, so the next scan re-parses every file once.
