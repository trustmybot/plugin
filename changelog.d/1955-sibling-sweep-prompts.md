### Changed
- **swe sweeps every case before it closes, and code-reviewer fails only on a blocking finding** (GH 1955): before closing, swe searches the diff and the changed code's callers for every other instance of each rule it changed and each open finding's kind, fixes the ones in scope, and lists the places it checked in `report.case_sweep`. code-reviewer now gives each finding a class (the kind of defect) and a severity (`blocking`, `nit`, or `pre_existing` for a defect already on the base), sweeps for every sibling of a finding before failing a review and records them in that one finding, and treats a sibling the swe's sweep missed as blocking. A review fails only on a blocking finding; nits and pre-existing defects ride on a pass. After a pass, bro bundles each nit into the next task on that surface or closes it as wontfix with a reason, and files each pre-existing defect as a GitHub issue. A rework's spawn note names each finding id with its class.
