### Added
- **`cli.js feature-branch drop|cleanup <name>` drops an agile feature branch or deletes it after its milestone PR merged** (GH 2225): `drop` moves every task merged onto the branch that still waits for the grouped review to `escalated` and records one `feature_branch_dropped` audit row naming them; the branch stays unless `--delete-branch` is passed. It exits 4 with nothing changed while a task of the branch is still live (pending, running, needs validation or completed), or when the branch has neither a local ref nor any task. `cleanup` deletes the local feature branch once a fetch of origin shows the remote copy gone, or at once when there is no origin, and exits 4 leaving it while it is checked out in a worktree or `origin/<name>` still exists. Each prints the SHA the branch is or was at (`drop` prints nothing for a branch that has only tasks); only `drop` writes the trajectory DB, and neither pushes.
