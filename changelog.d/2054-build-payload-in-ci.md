### Changed
- **Dev builds and release payloads now ship a payload CI built itself** (GH 2054): `dev-build.yml` and `release-payload.yml` install the dependencies and run the new `bun run build:payload` (server `dist/`, `dashboard/dist/`, `audit-events.txt`, `data-contracts.json`) before pruning, instead of publishing whatever `dist/` was committed. `release-gate.yml` and the L0 install-smoke image build the same way. A `dry_run` dispatch of `dev-build.yml` builds on any ref, checks the result against `dev-build` with the new `scripts/maintenance/payload-parity.ts` and cold-boots its MCP server, without pushing or commenting. Nothing changes for installs; this prepares for no longer committing generated files.
