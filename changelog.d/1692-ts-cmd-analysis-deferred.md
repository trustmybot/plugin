### Added
- **The TypeScript write-path analyzer now covers interpreter one-liners, find/fd/xargs exec and loop listers** (GH 1692): `mcp/trajectory-server/src/hooks/cmd-analysis/` now reads the files written by `python -c`, `node -e`/`-p`, `perl -e`/`-pi`, `ruby -e`, heredoc and here-string programs, `| python3 -`, `find -exec`/`-execdir`/`-delete`/`-ok`, `fd -x`/`-X`, `xargs` (including `-I` and `-0`), and loops fed by `$(find …)`, globs, `| while read` and `done < <(…)`. It prints the same lines as `tmb_cmd_write_paths` in `cmd-analysis.sh` on all 1398 commands in the corpus, apart from the same 12 recorded cases where it is stricter. It no longer prints `UNRESOLVED:$(deferred):…`. No gate uses it yet. Cold-process wall time, p50 of 10 runs on macOS with node 24.15 (`node -e 0` takes 27 ms), comparing `node -e` importing `dist/hooks/cmd-analysis/index.js` against `bash -c 'source cmd-analysis.sh; tmb_cmd_write_paths …'`: a `python3 -c "open('out.txt','w')…"` one-liner takes 55 ms and 46 ms; `find . -name '*.log' -exec rm {} \;` takes 52 ms and 40 ms; a `for f in $(find …); do sed -i …; done` loop takes 53 ms and 62 ms.
