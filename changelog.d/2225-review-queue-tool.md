### Added
- **A `review_queue` tool lists the agile-mode tasks still waiting for review** (GH 2225): bro calls it to see every closed task stamped `workflow_mode = 'agile'` that has no passing code-reviewer verdict and no review waiver or bypass from bro (or a bypass from close-issue-on-merge). It returns `{total, groups}`, where each group holds the tasks whose `files[]` overlap (the same path, or one inside the other's folder), with their task, branch and issue ids, commits and files. Tasks stay queued until reviewed or waived. Any other agent is refused.
