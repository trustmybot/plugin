### Added
- **A task can run in the session's own worktree** (GH 2032, GH 1692): when bro runs in a Claude Code worktree session (a linked git worktree), `task_provision`, `task_reopen` and `task_retry` now take `adopt_worktree: '<that worktree>'`. The task branch is checked out there and recorded as the task's worktree (`tasks.worktree_path`, `worktree_adopted = 1`), and no `<repo>/.claude/worktrees/<slug>` is created. The worktree is checked before anything is written, and for provision and retry before the branch is cut: a worktree of another repo, the main checkout, tracked changes, or a live task already holding it refuses the call with a typed error and leaves no task row, discussion, audit row or branch ref; a refused `task_reopen` leaves the task unchanged. `ADOPT_WORKTREE_ENABLED` is now on.
- **The `worktree-adopt-guard` hook** (GH 2032): a new TypeScript-only PreToolUse gate on those three tools. From a session in a linked worktree, a call without `adopt_worktree` is denied with the exact `adopt_worktree: '<worktree>'` to pass, and a different path is denied naming the one allowed. From a main checkout or a non-git directory, any `adopt_worktree` is denied. Paths are compared by realpath. Like every gate born in TypeScript, it does not run under `TMB_HOOKS_IMPL=bash`.
- **An adopted task auto-completes when swe stops** (GH 2240): `swe-atomic-close` now reads the task's recorded worktree (`tasks.worktree_path`) instead of building `<repo>/.claude/worktrees/<slug>`. A task running in the session worktree is completed at that worktree's head, and the no-commit warning and the `agent_runs.root_dir` it writes name that worktree. Tasks without a recorded worktree keep the slug path.
- **Known divergence until the bash helpers are deleted** (decision 910): for an adopted task, the TypeScript gates (`ensure-swe-worktree`, `record-swe-spawn`, `swe-boundary`, `containment-guard`, `swe-atomic-close`, worktree cleanup) use the recorded worktree, while the `.sh` helpers still use the slug path. The PR in GH 1692 that deletes the `.sh` helpers removes the difference.
