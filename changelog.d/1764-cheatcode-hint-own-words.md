### Fixed
- **Intent hints react only to what you typed** (GH 1764): the UserPromptSubmit intent hints read the whole prompt, including `<system-reminder>`, `<pasted_content>` and `<agent-message>` blocks the harness adds, so a reminder quoting another session ("no dependencies installed", "warning to swe") fired the cheatcode-routing hint on an unrelated prompt. Those blocks are now removed before any hint matches. The cheatcode-routing hint also needs `install` or `add` as a whole word followed in the same clause by `for`, `to` or `onto` an agent, so "I installed it. Then hand it to swe" no longer triggers it.
