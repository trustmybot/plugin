### Added
- **Bro offers a TMB bug report when TMB itself breaks, and files it only after you approve it** (GH 2034): `/onboard` now asks a fifth round, `Bug reports`, and its summary shows your answer; telling bro to stop or start offering reports changes it later. With `yes`, after a server error, a server crash, a `trajectory_doctor` violation, a hook deny bro can show is wrong, or when you say it is a TMB bug, bro drafts the report, checks whether it was already filed or already exists on github.com/trustmybot/plugin, and shows you the full text with File it / Edit first / Don't file. File it sends it from your GitHub account with `gh` (or gives you a prefilled link when `gh` is not set up) and records it, so the same error is not offered twice. Bro never offers a report for its own mistakes or for your code.
