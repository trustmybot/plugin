### Added
- **The world model flags READMEs that have drifted from their code, and sentence queries find hits** (GH 1680): each README-backed directory now records the commit that last touched its README (`summary_sha`), how many commits have landed under the directory since (`commits_behind`), and which paths the README names that no longer exist (`dead_refs`, e.g. a script git deleted). `world_model_get` and `world_model_search` show these on every directory, with a one-word `trust` verdict: `current`, `drifting(n)`, `dead_refs(k)` or both, and `null` for directories without a README. Keyword search now falls back from "every term" to "any term" (common English words dropped) when a full-sentence query matches nothing, and says which it used in a new `match` key (`all_terms` or `any_term`). Schema v43 adds the three columns in place; they fill in on the next `/scan`. Outside a git repo, or when git fails, they stay empty and the scan still succeeds.
