### Fixed
- **A tool call that leaves out `agent` now says so** (GH 1622): when `agent` was missing or not a plain lowercase name, the trajectory server answered with a bare `forbidden` / `caller_role: unknown` error that read like a role restriction, and a model could abandon its flow over a missing argument. The error now adds `reason: agent_missing_or_invalid`, the value it received, the valid names (`bro`, `swe`, `pr-reviewer`, or a consultant slug), and a message saying to retry with `agent` set. Calls from a known role that the tool doesn't allow get the same error as before.
