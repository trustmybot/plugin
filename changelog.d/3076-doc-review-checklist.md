### Added
- **One checklist for prompt and docs changes** (GH 3076): the new `tmb_doc-review` skill is the checklist bro, swe and code-reviewer share for a prompt-bearing task or a change to a path in the project's prompts or docs class. It loads the project's rubric from `prompts.rubric` in `.config/tmb/path-classes.json` at the base branch, so a change cannot edit the rubric that judges it, and falls back to a shipped generic rubric (`RUBRIC.md`, ids R1 to R12) when the project declares none. It grades each rubric id the change touches, fact-checks every claim the changed lines make about tools, CLI flags, hooks, paths and config keys against the source with one probe each, and scans the other prompt files for contradictions. A finding blocks only when a rubric id fails, a claim is false or unverifiable, or two files contradict; everything else is a nit. code-reviewer preloads the skill and records its findings in the same push-gate verdict, swe runs the checks before closing, and bro cites the rubric ids in a prompt-bearing spec and self-checks its own no-code changes before review.
