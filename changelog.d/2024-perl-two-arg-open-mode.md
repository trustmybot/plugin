### Fixed
- **A perl 2-argument read `open` no longer counts as a write** (GH 2024): `perl -i -pe 'BEGIN{open(F,"agents/a.md")}' src/a.ts` was judged to write `agents/a.md` and printed `UNRESOLVED:$(unproven)`, because the leading `a` of the path read as Python's append mode. A mode letter now counts only as a whole mode argument (`open(p, "a")`, `mode="w"`), and a perl 2-argument open takes its mode from the string's leading `>`, `>>`, `+<` or `+>`, so the command above lists only `src/a.ts`. A write prefix still lists its target, and an open whose string holds a pipe, `-`, an interpolation or an escape still fails closed.
