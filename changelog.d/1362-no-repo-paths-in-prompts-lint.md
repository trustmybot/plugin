### Added
- **Shipped prompts can no longer name this repository's own paths** (GH 1362): a new L1 lint, `no-repo-paths-in-prompts.sh`, fails when an agent, command, template or skill prompt names a repository-specific path or script (the server source tree, hook and maintenance scripts, the changelog fragment directory, test layers, `regen-generated`, `dist-fresh`, the architecture docs). Lines naming the installed plugin's own internals (`CLAUDE_PLUGIN_ROOT`, `.claude/tmb/`, kuzu, the plugin cache) stay allowed. It runs in `tests/run-all.sh` with a `--self-test` against two fixtures.
