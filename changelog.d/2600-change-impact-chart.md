### Added
- **Change impact chart** (GH 2600): the Change impact detail panel in Insights now charts one metric per day around the change. A Metric select picks the metric, starting on the first one that improved or regressed. Each column is one UTC day's median on one side of the change, before columns in grey and after columns in blue, with a Before and After legend and a `change` marker at the first after column; a day can hold both sides, because plugin versions split by build, not by time. Hovering or focusing a column reads its day, side, median and run count, and View as Table lists Day, Side, Samples and Median. A metric with no runs in the window reads "No samples in this window." The detail form of `GET /api/insights/change-impact` now carries each metric's daily `series`; the list form and the `change_impact` tool are unchanged.
