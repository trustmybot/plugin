### Fixed
- **The L3 verification-gate minimal-PATH test holds when node comes from mise or homebrew** (GH 1358): its precondition built the reduced PATH from the bin dirs of the hook's deps, so on a host where node shares a dir with one of them (homebrew's `timeout`) node stayed resolvable and the case failed, failing the full L3 run and with it every hook task's close through the verification gate. The minimal PATH is now a fresh dir of symlinks to exactly the hook's deps, the precondition runs with the mise/asdf/nvm variables unset, and a failure names the path node resolved to.
