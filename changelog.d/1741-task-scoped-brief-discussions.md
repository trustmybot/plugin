### Fixed
- **A task brief carries only that task's decisions** (GH 1741): `task_brief` used to include every decision and intent on the issue at full length, so a long-lived issue made each swe and pr-reviewer spawn read every task's decisions. A brief now holds this task's decision/intent rows, the newest issue-level decision and the last 8 notes, skips any row a later one supersedes, and points to `discussion_search(issue_id=N)` for the full history. Schema v46 adds `discussions.task_id`, which `task_provision`, `task_retry`, `task_reopen` and `task_update_spec` fill in, and `discussions.supersedes`; `discussion_append` takes both as optional arguments. Rows from before v46 stay issue-level. The root directory no longer lists itself as its own child in the brief's world-model scope.
