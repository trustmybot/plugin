- **`scope_suggest`'s draft is usable as-is for a spec** (GH 3145, GH 3158): `draft.verification` held build, install and CI-plumbing commands (esbuild, `bun install`, `git config`) instead of the tests it found, and `draft.files` pulled every weak search hit.
