### Fixed
- **`cli.js integrate` keeps new regenerated files** (GH 2353): when the regen step renamed a generated file (such as a content-hashed `dashboard/dist/web/chunks/*.js` chunk), the amend staged the old name's deletion but not the new file, so the integrated commit imported missing chunks. The amend now stages every change under the `merge=tmb-regen` paths, new files included, and still leaves everything outside those paths out of the commit.
- **A dashboard build in a task worktree gives the same chunks as the main checkout** (GH 2353): both esbuild calls in `dashboard/package.json` now pass `--preserve-symlinks`, so a worktree's symlinked `node_modules` no longer changes the chunk hashes. `dashboard/dist/web/chunks/` drops the five unreferenced chunks a worktree build left behind, and `dashboard/test/build.test.mjs` checks the flag and that the chunks match what `app.js` imports.
