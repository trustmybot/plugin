### Added
- **A quick check for docs and comments a change left stale** (GH 1955): `node --experimental-sqlite mcp/trajectory-server/dist/cli.js stale-docs <base> [--head <sha>] [--max-hits <n>]` takes the identifiers a diff touched in code (snake_case and camelCase names, long kebab-case names, and each changed file's name) and lists the Markdown lines and code comments that still name them, one `path:line: token` line each: lines the diff did not touch, and lines it edited while keeping the old mention as it was. Without `--head` it checks your uncommitted work, so you can run it before you commit. Tokens found on more than `--max-hits` doc lines (15 by default) are skipped as too common. It only advises: it exits 0 whether or not it flags anything, and 2 on bad usage or a git error. `scripts/maintenance/stale-docs-eval.ts` replays it on past changes whose reviews found stale docs and reports how many of those findings it would have caught.
