### Changed
- **The grouped agile review hand-off runs the full test suite, and the review queue filters by feature branch** (GH 2225): `review_batch_handoff` used to run only the close lints at the feature-branch tip. Once they pass, it now also runs each command in the repo's `.config/tmb/verification-defaults.json` there, in the same temporary worktree, and a failing command refuses the hand-off with `suite_failed`, naming the command and the end of its output. The hand-off result and its audit row record the commands that ran as `suite`; a repo with no such file runs no suite and the result says so. `review_queue` takes an optional `feature_branch` to list only the tasks merged onto that branch.
