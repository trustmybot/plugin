### Fixed
- **`scripts/health.sh` reports degraded embeddings, checks the install it runs from, and no longer FAILs a process table it cannot list** (GH 1670): it printed `all checks passed` while semantic search was on its FTS fallback, because it had no embeddings check. A new `embeddings` check uses the `trajectory_doctor` contract `embeddings_not_degraded` (an `embeddings_degraded` audit row from the last 24 hours with no later `embeddings_recovered` row). When it trips, the check prints a `WARN` with the time and reason, and the footer reads `no check FAILED, 1 degraded` in place of `all checks passed` (exit code still 0). Run without `CLAUDE_PROJECT_DIR`, the script used to check the first installed entry, often the stable `trustmybot/tmb` cache, and reported false FAILs. It now checks the plugin root it runs from (`CLAUDE_PLUGIN_ROOT`, else the script's own install). When `pgrep` exits 2 or higher, as in the Claude Code sandbox, `server-reachable` prints `UNVERIFIED` and the run does not fail.
