### Fixed
- **PRs, comment triage and reviews target the task's repo from any working directory** (GH 1553): the push gate created PRs/MRs and comment triage looked up the PR in whatever repo the session sat in, and a pr-reviewer spawn could leave out the repo path. Now `gh pr create` / `gh pr view` and `glab mr create` / `glab mr list` pass `-R <slug>` from the task's repo, a pr-reviewer spawn prompt without `repo_path=` is denied, and a new lint fails on any prompt that uses a relative `.claude/` path or runs `git push`, `git switch`, `git checkout` or `git pull` without `-C`.
