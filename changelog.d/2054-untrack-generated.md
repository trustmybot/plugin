### Changed
- **The repo no longer commits generated build output** (GH 2054): `mcp/trajectory-server/dist/`, `dashboard/dist/`, `scripts/hooks/lib/audit-events.txt` and `scripts/hooks/lib/data-contracts.json` are untracked and ignored, since CI builds the published payload and worktrees and `tests/run-all.sh` build first. `.gitattributes` and the `dist-fresh.sh` lint are gone; a new L1 lint, `no-tracked-generated.test.mjs`, fails when any of those paths is tracked and names the `git rm -r --cached <path>` fix. The world-model scan reads `bundled_by` from built, ignored bundles on disk, so `world_model_symbol` still lists them. The code-reviewer preflight's `stale_doc_ref` check no longer counts a path the commit's own `.gitignore` files ignore as removed, so docs naming built outputs stay valid. Nothing changes for installs.
