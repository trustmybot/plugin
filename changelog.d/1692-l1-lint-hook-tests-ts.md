### Changed
- The code-quality-lint, commit-msg-lint and naming-lint hook tests, and the self-tests for the no-cwd-reads, legacy-reviewer-name, no-directories-table-refs and prompt-explicit-paths lints, are now node:test files under `mcp/trajectory-server/src/test/` (`lint-hooks-l3.test.ts`, `l1-lint-scripts.test.ts`) that run in `npm test`, with every assertion kept (GH 1692). The hook cases run `node dist/hooks.js <hook>` with the project pinned to a sandbox; the lint cases run `bash tests/l1-lint/<script>.sh` against the same planted fixture trees. The seven `tests/l3-integration/hooks/*.test.sh` files are gone.
