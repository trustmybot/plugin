### Added
- **A page for each task in the dashboard** (GH 1347): click a task in the Tasks tab, or a task id or title in Runs & gates, to open `#/tasks/<id>`. It shows the task's spec, its files and verification commands, swe's completion report criterion by criterion, every review verdict with its feedback, the review findings with their probe, expected and observed output, each verification run with every command's exit code, time and output, and the task's agent runs with their token counts. Before this, a task click jumped to its issue and none of this was visible. Command output is shown as plain text, so nothing in it can run in the page.
