### Changed
- **The L0 install smoke runs on macOS, Linux and Windows** (GH 1749): its assertions move from the per-step `RUN` lines of `install-smoke.Dockerfile` into one Node driver, `node --experimental-strip-types tests/l0-install/install-smoke.ts`, which needs no shell scripts. The Docker image now only provides the Linux host for it. release-gate runs install-smoke as a matrix: Linux in Docker as before, and macOS and Windows host-native. The driver works on a temp copy of the plugin with its own `HOME`, `CLAUDE_CONFIG_DIR` and `CLAUDE_PLUGIN_DATA`, so a local run never touches your `~/.claude`. On Windows, where there is no data-dir bridge link, it checks that the SessionStart hook installs `@huggingface/transformers` into the installed MCP directory instead.
