### Added
- **Agile review mode now runs end to end** (GH 2225): `/onboard` asks for the project's review mode, truest or agile, and only the Human changes it there. Under agile, bro cuts one feature branch per milestone, closes each task with no per-task review, lands it on the feature branch with `cli.js feature-merge` and pushes the branch as a backup with no PR. When the Human says the milestone is reached, bro syncs the working branch in, hands each group of queued tasks to its own code-reviewer in parallel, turns a failed group into a reviewed fix task, records a waiver only after the Human answers Yes, and then opens one PR into the working branch. code-reviewer judges a group's net diff and records one verdict for it with `review_batch_record`.
