### Added
- **An agile feature branch is proposed for merge only once its grouped review is settled** (GH 2225): opening a pull or merge request (`gh pr create`, `glab mr create`) from a feature branch is now blocked while any agile task merged onto it is still queued for review. It goes through once a code-reviewer records a passing grouped review, or once the Human has said yes to merging without that review and bro records the answer with the new `review_waive_record` tool. That record names the branch's queued tasks at their current commits and quotes the Human's answer; a waived task leaves the review queue, the doctor's agile backlog and the issue-close check. A task merged onto the branch later is queued again and blocks the request until it is reviewed or waived too.
