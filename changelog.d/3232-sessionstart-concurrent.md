### Changed
- **SessionStart checks run side by side and read the process list once** (GH 3232): the default SessionStart hook's seven checks now run at the same time instead of one after another, so a session starts sooner. The orphan scan and the deferred-tools drift warning share one process-list snapshot instead of running `ps` once per process they look up, and the MCP health check's wait between samples no longer blocks the other checks. The hook's time limit drops from 32 s to 17 s to match. The inventory and `.gitignore` checks run their per-repo `git` calls in parallel and print in the same order as before. All output is the same, except that stderr lines from different checks can now appear in a different order.
