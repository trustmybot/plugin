### Fixed
- **The code-reviewer preflight no longer blocks a branch whose only base conflicts are regenerated files** (GH 2005): `base_conflict` denied whenever `git merge-tree` reported a conflict, including rename/delete and modify/delete conflicts on hashed build chunks such as `dashboard/dist/web/chunks/*.js`. The `tmb-regen` merge driver never runs for those, and `integrate.sh` won't run without a passing review, so the two deadlocked. The preflight now reads each conflicted path's `merge` attribute from the task commit's tree (`git check-attr --source=<commit>`). When every path is `merge=tmb-regen`, the conflict is waived and the remaining checks run. Any other conflict still denies, and the denial now lists only the non-regenerated paths. A failing `git check-attr` also still denies.
