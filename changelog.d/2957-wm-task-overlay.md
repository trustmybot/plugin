### Added
- **The world model sees a task's own branch while the task is in review** (GH 2957): when swe closes a task, the plugin indexes the files the task's commit changes against its base into a per-task overlay, and leaves the shared index alone. `world_model_symbol`, called in that task's context, now finds the symbols the branch adds or changes, hides the ones it deletes, and names the overlay in a new `overlay` field. Calls outside the task see only the shared index. A later close replaces the overlay, and a rebase rebuilds it on the next read. Retrying, escalating or closing the issue drops it, and so does the next reindex once the commit is merged. Each build adds a `wm_reindex` audit row with trigger `overlay`, the path count and the build time; the rework limit doesn't count these rows as world-model fixes. A docs-only task gets file rows only. Upgrading to schema v75 adds the `wm_overlays`, `wm_overlay_files`, `wm_overlay_symbols` and `wm_overlay_edges` tables.
