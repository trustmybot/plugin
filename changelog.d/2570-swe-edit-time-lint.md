### Added
- **swe gets the repo's lint failures on a file the moment it writes it** (GH 2570): a repo can list per-file lints in `.config/tmb/edit-lint.json` (`{"version":1,"lints":[{"glob":"<path glob>","command":"<cmd>"}]}`). After each swe Write, Edit or MultiEdit, the new `swe-edit-lint` hook runs every lint whose glob matches the edited file, as `<command> "<file>"` from the repo root, and blocks on the first failure with the command, its exit code and its last 20 output lines, so swe fixes the file in the same turn instead of finding out at close or in CI. Only the commands the repo declares run. Without the file, or with no matching glob, nothing runs. A malformed file, or a lint still running when the hook's 10 s budget runs out, gives swe a one-line note and no block.
