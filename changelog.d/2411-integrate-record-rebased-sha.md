### Fixed
- **code-reviewer can review an integrated head** (GH 2411): `cli.js integrate` moved the task branch to the rebased SHA but left `tasks.commit_sha` at the reviewed one, so `code-reviewer-preflight` denied a reviewer spawn on the integrated head with `sha_mismatch`. Integrate now sets `tasks.commit_sha` to the rebased SHA and writes a `task_integrated` audit row in the same transaction; that row anchors the review like `bro_verification_pass`, so after exit 0 bro spawns code-reviewer on the printed SHA, then pushes it. A failed write after the branch moved exits 4 naming the rebased SHA.
