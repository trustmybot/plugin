### Added
- **Compact test output** (GH 1907): `node mcp/trajectory-server/dist/test-run.js [--log <path>] [--max-lines <n>] -- '<command>'` runs one test command and prints a single summary line (`test-run: exit=… pass=… fail=… skip=… format=… log=… elapsed=…s`) followed by at most 10 failure excerpts of at most 40 lines each, instead of the full suite output. The complete raw output goes to a log file whose path is printed, and the wrapper exits with the command's exit code. It reads node test runner TAP and spec output and `tests/lib/assert.sh` summaries; any other output shows its last lines when the command fails.
