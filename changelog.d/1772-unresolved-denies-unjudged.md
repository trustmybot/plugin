### Fixed
- **Following an unresolved-target Bash block with an Edit is no longer reported as a bypass** (GH 1772): when containment-guard or swe-boundary blocked a Bash command because a write target sat behind a variable, a command substitution, a cd it could not follow, a non-literal process call or an aliased write builtin, the dispatcher still recorded the command's other literal paths, so the literal-path Edit or Write the block told the swe to use was flagged as `hook_block_bypassed`. Those denies now read `cannot be judged: …`, like the GH 1750 denies, and record nothing; a judged deny of a literal target is still recorded and flagged.
