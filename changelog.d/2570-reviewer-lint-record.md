### Changed
- **The reviewer preflight checks swe's lint record, and the reviewer runs no lints** (GH 2570): before a code-reviewer spawn, `code-reviewer-preflight` now requires the task's newest finished close-lint run for the commit to have passed (`no_lint_record`) and to still be current: the same fingerprint and merge-base the commit has today, a passing result for every lint in `.config/tmb/close-lints.json`, and a config that parses (`stale_lint_record`). Anything it cannot prove current and clean is denied, with the run id and the recorded and recomputed values. The code-reviewer runs no lints or repo checks, and a lint failure is not a review finding. `close-lints.json` now rejects two lints with the same name.
