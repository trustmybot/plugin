### Changed
- **The trajectory-server starts without probing every MCP server** (GH 1698): each boot ran `claude mcp list` and `claude plugin list --json` to reconcile cheatcode status. `claude mcp list` health-checks every configured MCP server, which took about 4 s and contacted every remote host. Startup now runs these probes only when an `active` or `broken` mcp or plugin cheatcode exists and the Claude Code config that feeds them has changed. That config is the `mcpServers` maps, `.mcp.json`, `enabledPlugins` and `installed_plugins.json`. Startup also probes when the last probe is more than 24 h old. The fingerprint and probe time are cached in `.claude/tmb/cheatcode-probe.json`. `cheatcode_reconcile` still probes on every call.
