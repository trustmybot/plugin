### Changed
- **One gh or glab call no longer freezes every other lane** (GH 3232): the MCP server serves every lane and subagent from one process, and its GitHub/GitLab calls (issue, milestone and PR sync, issue reconcile, PR comment fetch, the `auth status` checks behind issue sync and `/onboard`) used to block that process for the whole 0.3–2 s remote call. They now run without blocking it, so other tool calls keep answering while one waits on the remote, and an issue synced to both GitHub and GitLab is created or edited on both at the same time. Results and errors are unchanged.
