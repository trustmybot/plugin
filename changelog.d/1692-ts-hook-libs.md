### Added
- **TypeScript ports of the hook DB, audit, role and agent-context libraries** (GH 1692): `mcp/trajectory-server/src/hooks/lib/` now carries TypeScript versions of `query-task.sh`, `db-write.sh`, `normalize-role.sh` and `agent-context.sh`, with the same output text. They read the trajectory DB through Node's built-in `node:sqlite` with no extra flags and no warning, and fall back to the `sqlite3` CLI when that is unavailable. A differential test runs every port against its shell library on sandbox DBs (missing, empty, WAL warm and cold, locked, corrupt) through both paths. Hooks do not use the ports yet; the shell libraries are unchanged.
