### Changed
- **Contributing docs state the three layers of knowledge** (GH 2807): `docs/contributing/README.md` replaces its docs-level note with one rule: every fact about the codebase lives in exactly one layer. Docs hold architecture and never name a class, function, file, column or enum value; the world model holds relationships between symbols and the concepts anchored to them, generated rather than hand-written; code holds logic, with comments only for a non-obvious why. A fact in the wrong layer moves, never copies. Freshness-tested generated sections such as the `ENUMS.md` table may still carry detail, and drift is still fixed by deleting the detail.
