### Added
- **The dashboard shows how fresh the world model is** (GH 2593): the Project map keeps serving the last index while a reindex runs, and marks the repo Reindexing, Reindex failed or Stale beside the repo picker and the Dependency Graph heading, with the indexed and target commits on hover; the header shows Reindexing while any repo reindexes. The world-model endpoints carry a `freshness` block, and a new `/api/world-model/status` lists each repo's freshness and the recent reindex runs. World-model views now refetch when a repo's index lands instead of on every DB change, once the index records freshness; until then they refetch on every DB change as before.
