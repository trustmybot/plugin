### Added
- **Measure how many callers the world model misses** (GH 1988): `node scripts/maintenance/wm-caller-recall.ts` samples 100 TypeScript functions, methods and classes (fixed seed, so reruns draw the same ones), asks the TypeScript language service who references each, and compares that with the callers the world model records. It prints recall, precision and every miss sorted into a class (`unresolved`, `wrong_target`, `caller_not_indexed`, `no_edge`, and `false_edge` for callers the world model invents), with examples, or the full report with `--json`. It only reads the trajectory DB and the repo.
