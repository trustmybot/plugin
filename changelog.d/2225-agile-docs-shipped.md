### Changed
- **The architecture docs describe the milestone feature-branch model for agile mode and mark what has shipped** (GH 2225): agile work now builds on one feature branch per milestone. That branch is pushed only as a backup, tried in a separate worktree, synced with the working branch at the milestone, and merged as one PR. The docs no longer call these pieces planned: the project review mode question, the feature branch, closing without a per-task review, the queued, batch-reviewed and waived review states, and the merge gate with its audited waiver. The feature branch's batch review, grouping the queue by changed files, the agile agent prompts and lane review modes stay planned. Until the batch review ships, a Human waiver is the only way through the merge gate.
