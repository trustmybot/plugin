### Changed
- **The verification gate's budget is a project setting, and a timeout names the command** (GH 1284): the gate's budget came only from the `TMB_VERIFICATION_TIMEOUT_S` env var (900 s), which timed out twice on slow suites with no way to raise it in-project. It now reads `plugin_config.verification_timeout_s` (integer seconds, default 900, set with `config_set`; the env var still overrides it for tests), capped at 1800 s, and the gate's hooks.json timeout is raised from 961 s to 1830 s (`tests/l1-lint/hook-timeout-budget.sh` checks the cap against it). A spent budget marks the recorded run `timed_out` and the deny names the command that was running, its position and the cumulative time.
