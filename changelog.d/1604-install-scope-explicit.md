### Changed
- **Install and update commands name their scope** (GH 1604): `claude plugin install` defaults to user scope and `claude plugin update` picks one on its own, so the documented commands could install TMB user-wide. `docs/reference/INSTALL.md` is now the one place the rule lives: install at project scope for a team or local scope for yourself (and for the dev and rc channels), never at user scope, with the exact `--scope` commands to run from the project root. README, CONTRIBUTING, UPGRADE and the dev-build PR comment and step summary now pass `--scope` on every install, update and `marketplace add`, and link to INSTALL.md.
