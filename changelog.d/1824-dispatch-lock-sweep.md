### Fixed
- **Killed gates no longer slow down every later hook call** (GH 1824): the dispatcher's lock cleanup used to start one `find` per leftover lock, so a gate killed at its timeout made every later hook call slower for 20 minutes (one measured call took 3.55 s over 258 forks). The cleanup now runs in one pass (at most two `find`s and one `rm`, however many locks there are) and at most once per `TMB_DISPATCH_SWEEP_S` (default 60 s), timed by `.claude/tmb/locks/events.sweep`. Each lock now carries a `deadline` file (start + gate timeout + 5 s). A dead holder's lock is reclaimed once its deadline passes, and a live holder's lock is never removed before it, including a long verification run that outlives the old 30-minute cleanup.
