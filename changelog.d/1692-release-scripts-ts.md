### Changed
- **The release scripts run as TypeScript** (GH 1692): `scripts/release.sh`, `scripts/publish-rc-channel.sh` and `scripts/lib/await-release-gate.sh` become `scripts/release.ts`, `scripts/publish-rc-channel.ts` and `scripts/lib/await-release-gate.ts`, run as `node --experimental-strip-types scripts/release.ts` and `node --experimental-strip-types scripts/publish-rc-channel.ts [version] [--stable-repin] [--yes] [--dry-run]`. Prompts, defaults, refusals, exit codes and step order are unchanged; the scripts no longer need bash, `jq` or coreutils `timeout`. The `release-script-safety.sh` lint becomes the node:test suite `tests/l3-integration/release-scripts.test.mjs`, which also drives both scripts against stub `git`, `gh` and `docker`.
