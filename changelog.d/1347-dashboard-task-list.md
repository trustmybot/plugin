### Changed
- **The dashboard Tasks tab now looks like the Issues list** (GH 1347, GH 1641): each task is a row with its own status icon, a title link, a meta line (`#id status · branch · issue · updated`) and, on the right, the latest review verdict and the count of open review findings. Open and Closed tabs, a Status filter, search and sort sit above the list, and the filters live in the URL (`#/tasks?state=closed&status=running&branch=…&issue=…&q=…`), so a filtered view can be bookmarked. Clicking a branch filters the list to it; branch and issue filters show as chips you can remove. `/api/tasks` rows now carry `last_verdict` and `open_findings`. In Runs & gates, the Agent columns show each agent's avatar, and `code-reviewer` gets the same colour as `pr-reviewer`.
