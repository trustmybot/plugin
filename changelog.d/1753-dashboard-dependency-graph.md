### Added
- **A file dependency graph on the dashboard's Project map** (GH 1753): the Project map now opens on a graph centred on one file, with the files that use it on the left and the files it uses on the right, grouped into folders. Hover a file to see its edges and summary, click it to make it the focus, switch to 2 hops to see one level further, and use the side panel to list and sort its dependents and dependencies. A new read-only `GET /api/world-model/graph` serves the file-level edges. Summaries that start with a `---` rule now show their first real line, and empty table cells no longer show "null" on hover.
