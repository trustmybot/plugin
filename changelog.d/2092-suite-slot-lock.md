### Changed
- **Full test suites from parallel worktrees take turns** (GH 2092): `test-run.js` and the swe verification gate now wait for a machine-wide suite slot before a full suite (`bun run test`, `npm test`, `tests/run-all.sh`, or `node --test` with a glob or no file), so parallel swes no longer stack suites until hooks run out of time. Named test files, lints and other commands still run straight away. One slot by default; `TMB_TEST_SUITE_SLOTS` raises it, and `TMB_SUITE_LOCK_DIR` moves the lock root from `/tmp/claude-<uid>/tmb-suite-lock`. While waiting, stderr prints `waiting for a suite slot: held by pid P (worktree W) for Ns` at the start and every 60 s. The gate's wait does not count against `verification_timeout_s`; once it would outlast the hook timeout, the gate denies with `suite slot busy`, names the holder, and records no run. A slot left behind by a killed process is reclaimed, and a suite run inside a slot holder (`TMB_SUITE_LOCK_HELD`) shares that slot.
