### Removed
- **The `tmb-regen` merge driver and the integrate regen step are gone** (GH 2054): with generated outputs untracked, nothing routes a path to the driver, which only hid conflicts, so a local merge check could call a branch clean while GitHub said CONFLICTING. The WorktreeCreate hook no longer writes git config, `hooks.js install-merge-driver` and `scripts/maintenance/regen-generated.ts` are removed, `cli.js integrate` no longer regenerates or amends and compares patch-ids over every path, and the code-reviewer preflight's `base_conflict` check denies a conflict on any path. A `merge.tmb-regen` entry left in a repo's git config is inert.
