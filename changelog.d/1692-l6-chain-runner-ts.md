### Changed
- The L6 chain runner has a TypeScript port (GH 1692, wave 2 part 2b). `node --experimental-strip-types --experimental-sqlite tests/l5-l6/run-l6-chain.ts` takes the same `--from N`, `--halt-on-fail 0|1`, `--fresh` and `--self-test` flags as `run-l6-chain.sh` (an unknown flag exits 2), drives the same manifest steps with auto-resume from the newest prior run's `step-(N-1)/checkpoint.db`, writes the same per-step artifacts and run summary, and still fails a run whose isolated HOME holds anything but `.cache/huggingface`. It is built on the `tests/l5-l6/lib/*.ts` helper libs, passes the env as an object instead of writing `process.env`, and exports `main(argv, opts)` so `run-l6-chain.test.ts`, a new L3 step of `tests/run-all.sh`, can run it with a stub step runner and stub scorers and check every `--self-test` case. `run-l6-chain.sh` stays the caller-facing runner until part 2c.
