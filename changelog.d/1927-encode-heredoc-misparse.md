### Fixed
- **A push hidden after a misparsed heredoc no longer slips past the push gate** (GH 1927): tree-sitter-bash reads a heredoc whose delimiter is quoted mid-word (`cat <<E"M"`) or whose body has a line that is only `$` as running to the end of the command, so a `git push` after it looked like heredoc text. The TypeScript command analyzer now reports such a command as unparseable. The TypeScript git-push-guard denies any command naming `push` that it cannot parse, and the TypeScript write-path analyzer prints `UNRESOLVED:$(parse):…` for it, so containment-guard denies it too. `cmd-analysis.sh` is unchanged.
