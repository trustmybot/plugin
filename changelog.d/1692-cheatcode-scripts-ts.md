### Changed
- **Cheatcode search, vet, install and uninstall run in-process as TypeScript** (GH 1692): `cheatcode_search`, `cheatcode_vet`, `cheatcode_install` and `cheatcode_uninstall` no longer fork `scripts/cheatcode-*.sh`; their engines live in `mcp/trajectory-server/src/tools/cheatcode-{search,vet,install,uninstall}.ts`, so the tools no longer need bash, `jq`, `curl` or `timeout`. Inputs, output JSON, the `TMB_CHEATCODE_*_FIXTURE` variables and the project-root default fixture files are unchanged. A failed engine call now reports `cheatcode_<tool> failed: {"error":…}` instead of `cheatcode-<tool>.sh failed (exit N): …`. The six L3 shell suites move to node:test (`src/test/cheatcode-{search,vet,install,uninstall,activate}.test.ts`).
