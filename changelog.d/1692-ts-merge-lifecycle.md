### Changed
- **The merge-lifecycle hooks have TypeScript versions** (GH 1692): two PostToolUse(Bash) hooks are ported from `scripts/hooks/<gate>.sh` to `mcp/trajectory-server/src/hooks/` and listed in `dist/hooks-gates.txt`, so `dispatch.sh` runs them through node (`TMB_HOOKS_IMPL=bash` still runs the .sh). Their policy, bypass variables, messages and DB writes are unchanged:
  - `clean-merged-branch` deletes a merged head branch and its clean worktree after a successful `gh pr merge` / `glab mr merge`, keeps protected, unmerged and dirty-worktree branches, then runs a detached `git fetch --prune`. `TMB_DISABLE_CLEAN_MERGED_BRANCH=1` turns it off.
  - `close-issue-on-merge` closes the merged branch's live tasks and their open runs, records `review_gate_bypassed` for each task with no passing review or recorded skip, closes each issue the PR names by a closing ref unless another of its tasks is live, and closes the remote twin while issue sync is on. `TMB_DISABLE_CLOSE_ISSUE_ON_MERGE=1` turns it off; `TMB_DISABLE_REMOTE_SYNC` keeps the remote close off.

  A 35-payload corpus in `tests/fixtures/hook-corpus/` runs each hook through both versions against a sandbox repo with worktrees, a seeded trajectory DB and a stub `gh`. Both versions exit the same way, print byte-identical stdout and stderr, and leave identical refs, worktrees, `gh` calls and issue, task, agent_run and audit rows behind. The `clean-merged-branch` and `close-issue-on-merge` l3 suites pass against both versions; `TMB_HOOK_TEST_IMPL=ts` picks the TypeScript one.

  The TypeScript hooks differ from the .sh only where they no longer need a CLI tool (decision 703). Each difference has a payload in the corpus marked `corpus_divergent`:
  - **No jq needed.** Without jq, each .sh exited untouched. The TypeScript `clean-merged-branch` still cleans the merged branch, and `close-issue-on-merge` still reads the PR and closes its issues.
  - **No `sqlite3` CLI needed.** The TypeScript hooks read and write the trajectory DB through Node's built-in `node:sqlite`. Without `sqlite3`, the .sh `clean-merged-branch` ignored `repos.target_branch` and `repos.protected_branches` and fell back to `main` as the base, and `close-issue-on-merge` skipped the merge; the TypeScript hooks honour both columns and record the merge.

  The TypeScript `close-issue-on-merge` also bounds every `gh` call to 10 s on hosts without `timeout`, where the .sh ran `gh` unbounded.
