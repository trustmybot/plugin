### Changed
- **World-model tools pick the repo you are working in when you leave `repo` out** (GH 1968): in a multi-repo project, `world_model_get`, `world_model_search`, `world_model_symbol`, `world_model_concepts` and `world_model_concept_upsert` used to return `warning: 'repo-unspecified'` whenever `repo` was omitted. They now use the registered repo whose path contains the server's working directory (the deepest one when repos nest, matching whole path segments and following symlinks), then the sole registered repo, and only then warn as before. The read tools report which rule applied in a new `repo_source` field: `'arg'`, `'cwd'` or `'sole'`.
