### Changed
- **`task_brief` records the brief-fetched sentinel itself** (GH 1218): the `swe_brief_fetched` audit row (one per task, read by `swe-brief-gate`, `bro-turn-usage` and `agent_runs_backfill`) was written by the `swe-brief-gate` hook, so a failed hook write left the swe blocked with only an advisory hint. The `task_brief` handler now writes it when a swe fetches its brief, once per task and with the same `{task_id, agent_type}` content; a bro or pr-reviewer call writes nothing. `swe-brief-gate` only reads the sentinel, so Edit/Write and trajectory tools are denied until it exists exactly as before, and the event's writer set is `['swe']`.
