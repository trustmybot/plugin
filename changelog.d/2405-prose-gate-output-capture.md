### Fixed
- **Command output can go into a `.txt` or `.md` scratch file again** (GH 2405): the no-prose-in-scratch gate denied every redirect into a prose file under `/tmp` or `$TMPDIR`, so captures such as `git diff A B | grep x > $S/a.txt` or `gh issue view 1 --json body -q .body > $S/issue.md` were blocked as if they were drafted plans. A redirect (`>`, `>>`, `>|`, `&>`) is now judged only when its statement writes text of its own: a heredoc or here-string, or `echo`, `printf` or `cat` with no file operand, in the statement or as its pipeline's first command. Those, `cp`/`tee`-style writes, the Write and Edit tools, and `gh ... --body-file <file>` stay denied.
