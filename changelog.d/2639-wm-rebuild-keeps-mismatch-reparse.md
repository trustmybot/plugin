### Fixed
- **A full world-model rebuild now reparses every file while a shadow-compare mismatch is pending, whatever started it** (GH 2639): when the daily shadow compare found the index differed from a clean rebuild, the next full rebuild reparsed every file only if the mismatch was its reason. A rebuild started for another reason (a missing or unreachable indexed commit, an extractor version change, or `/scan`) kept the stored rows and parse stamps, so the bad rows survived, and still cleared the mismatch, so nothing rebuilt them later. Any full rebuild that runs while a mismatch is pending now reparses every file of that repo before it clears the mismatch.
