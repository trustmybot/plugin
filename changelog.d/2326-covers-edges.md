### Added
- **The world model knows which lint and test runners check each directory** (GH 2326): the symbol index now records every `package.json` script, Makefile, justfile, Taskfile and `pyproject.toml` target, and every GitHub Actions and GitLab CI step, as a `runner` symbol, with a `covers` edge to each repo directory its command names. A glob counts by its fixed prefix (`node --test tests/unit/*.test.mjs` covers `tests/unit`), a path argument counts when it is an existing directory (`eslint src lib`), and `cd pkg && npm test` covers `pkg`. Commands with no path argument, such as `tsc --noEmit`, cover nothing. `world_model_get` lists the runners covering each directory, or one of its parents, as `covered_by`. The extractor version moves to 13, so the next scan re-parses every file once.
