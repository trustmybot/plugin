### Added
- **Edit, comment on and close issues from the dashboard** (GH 1347): the issue view now has an Edit form (objective, description, priority, labels, milestone), a comment box and a Close button. Each write goes through the same trajectory-server handlers bro uses (`issue_update`, `issue_update_description`, `discussion_append`, `issue_close`), so the label rules and close refusals are the same. A close that still has open or unreviewed tasks is refused and lists them; nothing is force-closed. Comments are stored as Human notes, and every write adds an audit row marked `actor: human`, `source: dashboard`. Writes are accepted only from the dashboard page itself, which carries a per-launch token and must come from `http://127.0.0.1:<port>`. A write is refused with 409 when the DB schema does not match the dashboard's (open a Claude Code session to upgrade it, then restart the dashboard) or when the issue changed since you loaded it (reload and retry).
