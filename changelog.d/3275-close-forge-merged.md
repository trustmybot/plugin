### Fixed
- **A task whose PR was merged on the forge now closes on its own** (GH 3275): close-issue-on-merge only saw a merge made by a Bash call of the session, so a PR merged in the GitHub UI, by a merge queue or from another machine left its task live with no clean way to close it. At session start and on each prompt, the new `close-forge-merged` hook asks `gh pr list --state merged` (one call per repo with a live task branch, bounded to 10 s) for the newest merged PRs, and closes each live branch whose PR merged after its newest task was created, with the same bypass row and issue close a session merge writes. It fails open: with gh missing, failing, slow or printing bad output it writes nothing and the next turn retries. Bypass with `TMB_DISABLE_CLOSE_FORGE_MERGED=1`.
