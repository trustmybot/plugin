### Fixed
- **A `$` inside single quotes or after a backslash in a Bash write path is now judged as written** (GH 2443): the write-path analyzer used to expand it, so containment-guard judged `touch '$HOME/x'` as a write under your home directory and `touch '../$PWD'` as a write to some other path, when bash writes `x` in a directory literally named `$HOME`, and a file literally named `$PWD` one level up. Inside `'…'` or `$'…'`, and after a backslash (unquoted or inside `"…"`), a `$` now stays literal and the path resolves against the current directory; an unescaped `$` inside `"…"` and an unquoted `$` still expand. containment-guard now also judges an absolute path that holds a literal `$` or backtick (`touch /etc/a$`) instead of letting it through unjudged.
