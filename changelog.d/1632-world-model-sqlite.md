### Changed
- **The world model now lives in the trajectory DB, and the `kuzu` dependency is gone** (GH 1632): directories and files are `wm_directories` / `wm_files` tables (schema v42) with FTS5 indexes and embeddings, and the tree walk is a recursive CTE. Moving off Kuzu removes the failure modes it brought: a second session or an orphaned server holding the graph write lock (`graph_db_open_failed`), a native destructor segfault at exit on Node 24/macOS, a missing native binding after install, and a 531 MB install from an archived upstream. `world_model_search` keyword mode now ranks by FTS5 bm25 instead of a flat substring match, and semantic/hybrid modes work: hybrid fuses keyword and embedding hits by reciprocal rank and falls back to keyword hits with `warning: 'semantic_unavailable'` when no model is loaded. Existing Kuzu graphs are not migrated; run `/scan` once after upgrading to rebuild the map. The old `world-model.kuzu` directory can be deleted.
