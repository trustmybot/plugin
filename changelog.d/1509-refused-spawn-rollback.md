### Fixed
- **A refused swe spawn no longer blocks its respawn for 10 minutes** (GH 1509): a swe spawn refused after the spawn hook had recorded it left the task `running` with an unbound `agent_runs` row that counted as a live swe run for 10 minutes. A new PostToolUse(Agent) hook (`swe-spawn-bind.sh`) now binds an accepted spawn's row to its agent id at once. A new PermissionDenied(Agent) hook (`swe-spawn-rollback.sh`) closes the row of a spawn auto mode refused as `swept_orphan` and returns the task to `pending`. An unbound row now counts as live for 90 s instead of 10 minutes; after that, the next spawn and the SubagentStop hook close it as `swept_orphan`. This covers manual denials, deny rules and hook blocks. Rows bound to a running swe are never touched.
