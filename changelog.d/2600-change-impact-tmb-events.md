### Added
- **Change impact covers cheatcode installs, uninstalls and config changes** (GH 2600): `change_impact` has a third source, `tmb_events`. Each cheatcode you install is a change (id `cheatcode-<n>`), and so is each uninstall and each config change (id `audit-<n>`). Like `agent_surface`, the runs split at the change's time. Cheatcodes that ship with TMB are not listed; the plugin version already covers them. To give a config change a time, `config_set` now writes a `config_changed` audit row for each key whose value changes. The row names the key only, never the value, which can hold a secret. Setting a key to the value it already has writes no row. Config changes made before this release have no row, so they are not listed.
