### Added
- **The world model indexes Perl, and shows which built bundles inline a source file** (GH 2284): `/scan` now reads `.pl` and `.pm` files and scripts with a `perl` shebang, indexing each named `sub` as a function and each `use constant` name (single or block form) as a constant, with line numbers. A built `.js` or `.mjs` file with a committed source map now links to each repo file the map lists, skipping `node_modules` and paths outside the repo, and `world_model_symbol` on a source file lists those bundles in a new `bundled_by` field, so you know what to rebuild after an edit. The dashboard server bundle is now built with a source map. Schema v56 adds the `bundles` edge kind; existing DBs upgrade on the next session start.
