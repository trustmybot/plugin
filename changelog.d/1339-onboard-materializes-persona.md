### Added
- **`/onboard` puts bro's persona into the project's own CLAUDE.md** (GH 1339): Claude Code never loads a plugin's `CLAUDE.md`, so bro's persona and routing table were missing in every user project. `onboard_apply` now copies the plugin's `CLAUDE.md` into `<project>/CLAUDE.md` between `<!-- tmb:persona start v<version> -->` and `<!-- tmb:persona end -->`: appended when absent, replaced in place on a version or body change, left alone when identical, never touching your own text; `persona: false` removes it, the TMB source checkout is never rewritten, and each change writes a `persona_block_written` audit row. The SessionStart prescan prints a `Persona:` line when the block is missing or stale, and `trajectory_doctor` adds the warn contract `persona_block_current`.
