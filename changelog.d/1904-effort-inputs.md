### Added
- **World-model effort inputs per new task, in shadow mode** (GH 1904): every task `task_provision` or `task_create_batch` creates now gets one `effort_inputs_recorded` audit row with what the world model knows about the code its spec names in backticks: symbols resolved, direct callers, caller files outside `files[]`, tables written and their readers outside `files[]`, tests reached, plus the `high_effort_paths`, prompt-bearing and rework flags. The row also holds a suggested tier (`low`, `medium` or `high`) and its reason. `task_provision` returns the suggestion as `effort_inputs: {suggested_tier, reason}`. The effort a task runs at is unchanged; with no world model the row records `wm_available: false` and the task is created as before. `effort-ab-report.ts` now shows each enrolled task's suggested tier and a per-arm count, and `node scripts/maintenance/effort-inputs.ts --tasks <id,…> [--db <path>] [--repo <name>]` computes the same inputs for existing tasks from a DB opened read-only.
