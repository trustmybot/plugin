### Changed
- **Issue write tools no longer echo the description back** (GH 1372): `issue_create` (create, adopt-at-create and unresolvable-repo paths), `issue_update_description`, `issue_link`, `issue_adopt_remote` and `issue_close` returned the full description the caller had just sent (up to 1 MB), so every body cost the conversation twice, and the last four skipped role redaction. Each now returns the row through the same redaction as `issue_get`, without `description` unless `include_description: true` is passed (available on `issue_create`, `issue_update_description`, `issue_link` and `issue_adopt_remote`); id, objective, status, repo, milestone, labels, remote ids, `milestone_default`, `_sync` and `_adopted` are unchanged.
