### Fixed
- **Following a "cannot be judged" Bash block with an Edit is no longer reported as a bypass** (GH 1750): when the containment guard blocked a Bash command because it could not tell where it writes (a command that does not parse, or a path built at run time such as `python3 - <<'EOF'`), the dispatcher still recorded the command's paths, so the Edit or Write on the literal path that the block asked for was logged as `hook_block_bypassed` with a "hard stop, report to bro" message. Only blocks that judged a path are recorded now, and the run-time-path block names the accepted route: Edit or Write on the literal path, or a Bash command whose write target is a literal path. Edits after any other Bash block are still recorded and flagged as before.
