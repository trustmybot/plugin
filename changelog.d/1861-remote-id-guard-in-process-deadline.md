### Changed
- **The remote-id guard's deadline runs in-process** (GH 1861, GH 1692): in the TypeScript guard, the GH 1821 deadline is a time budget inside the gate rather than a killed process group. `TMB_REMOTE_ID_GUARD_DEADLINE_S` keeps its default of 3 seconds and its validation, and an invalid value still falls back to 3. On overrun the guard still allows, prints one stderr line and writes one `remote_id_guard_overrun` audit row on issue -1. Tests reach the overrun path through `TMB_REMOTE_ID_GUARD_TEST_OVERRUN=1`, which makes the budget read as spent, so no test waits on the clock.
