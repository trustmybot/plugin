### Fixed
- **Writing a report or scratch file outside any git repository is no longer blocked** (GH 1258): `no-source-edit-from-main` denied a `Write` to the session scratchpad (for example `/private/tmp/claude-501/<project>/<session>/scratchpad/compare/index.html`) because a target whose directory resolves to no git root fell through to the main-checkout source-edit deny. An absolute target whose existing directory sits inside no git repository is now outside the guard's scope, regardless of extension. A target whose parent directory does not exist still fails closed, and source files inside a registered repo are still denied from the main checkout.
