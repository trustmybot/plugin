### Changed
- **The sqlite3-needs-timeout L1 lint runs on node:test** (GH 1692, the runtime hook TypeScript port): `tests/l1-lint/sqlite3-needs-timeout.sh` is now `tests/l1-lint/sqlite3-needs-timeout.test.mjs`, with the same scan targets, shell lexing rules, wrappers, variable and array tracking, `eval` / `sh -c` re-lexing, `find -exec` handling, allowlist format and failure messages; its perl shell lexer is now JavaScript, so the lint no longer needs perl or bash. The former `--self-test` checks on `fixtures/sqlite3-needs-timeout/` are now cases in the same file and still run before the repo scan, and new cases check that an allowlist entry with no reason or no hit fails.
