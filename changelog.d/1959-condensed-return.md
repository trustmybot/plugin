### Changed
- **swe and code-reviewer hand bro a one-line summary instead of a long report** (GH 1959): `task_update_status` and `validation_record` now return a `return_line` built from the row they just wrote (`status=… task=… sha=…` for swe, `verdict=… task=… sha=… attempt=… row=… findings=…` for code-reviewer). Each agent's final message starts with that line verbatim, followed by at most 4 short lines only for what bro must decide or act on, such as a question or a quoted hook deny. The full report stays on the task or validation row, so bro's context grows more slowly. When a final message runs over 600 characters, the SubagentStop hook writes an advisory `subagent_return_oversize` audit row. It never blocks or changes the stop.
