### Added
- **The plugin repo lints each file swe edits as it edits it** (GH 2570): `.config/tmb/edit-lint.json` maps every path, dot directories included, to `tests/l1-lint/file-lint.ts`, which runs the file-scopable L1 lints (secrets, cwd reads, `/tmp` and home writes, hardcoded plugin name, developer paths, prompt paths and citations, wall-clock asserts, bare `mktemp`, CLI config scope, and warn-only negative directives) on the one edited file. Each lint's rule and scope now live in `tests/l1-lint/lib/`, so the edit-time check and the whole-tree CI check run the same code.
