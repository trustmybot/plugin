### Fixed
- **Hook gates no longer miss a keyword split by a line continuation or written in `$'…'`** (GH 2758): no-remote-auth-guard, remote-id-guard, ref-move-reindex, git-guards, git-push-guard, stay-on-base-guard, no-worktree-branch-create and branch-up-to-date-with-remote each check the command text for a keyword before any parse, and allowed the command at once when it was missing. A backslash-newline inside the keyword (`gh auth lo\` then `gin`, `--bo\` then `dy`) or ANSI-C quoting (`gh auth $'\x6cogin'`, `$'\x67it' $'\x70ush' origin main`) hid it from that check, while bash still ran it. The check now reads the command with its continuations joined and its quotes dropped, and sends every command holding `$'` to the analyzer, which decodes it, so each gate denies or reindexes as it does for the plain command. Commands with neither the keyword nor `$'` keep the fast allow, and no deny text changes.
