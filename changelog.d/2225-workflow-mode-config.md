### Added
- **A `workflow_mode` setting, recorded on every closed task** (GH 2225): the new `plugin_config.workflow_mode` key takes `truest` or `agile` and reads as `truest` when unset. It is the Human's choice: `config_set` refuses it with `human_only_config_key`, and `/onboard` is where it will be set. When `bro_atomic_close` or `task_recover` closes a task, the mode in force is stamped on the new `tasks.workflow_mode` column (schema v66). Open tasks, and tasks closed before the upgrade, carry no mode. Nothing changes behavior yet; later GH 2225 work uses the mode to mute the automatic code-reviewer in agile mode.
