### Fixed
- **Closing the last task no longer closes the GitHub/GitLab issue** (GH 3115): `bro_atomic_close` and `task_recover` with `close_issue_if_last_task` closed the remote issue as soon as the local one closed, even when the fix was not yet pushed. They now close only the local issue and return `remote: {deferred: 'pr_merge', remotes}` naming each linked issue; the remote closes when the PR that references it merges, by its closing keyword or by the close-issue-on-merge hook, which now also closes the remote issue of a closing ref whose local issue is already closed (with issue sync off it records the skipped close instead). `issue_close` still closes the remote issue right away.
