### Fixed
- **The world model keeps up with more ways the target branch moves** (GH 2584): the ref-move hook now also reacts to `git merge`, `git rebase`, `git reset`, `git checkout`, `git switch` and `gh repo sync`. A `gh repo sync` fetches the target branch first, like a PR merge. The startup catch-up now fetches `origin/<target branch>` for each repo before it reindexes, at most once per 10 minutes, so a new session sees commits merged elsewhere. A failed fetch still reindexes to the local ref.
- **A failed shadow compare now keeps the world model on full rebuilds** (GH 2584): before, a mismatch forced one full rebuild. Now every reindex of that repo is a full rebuild until the extractor or schema version changes. The mismatch and compare audit rows record that version as `stamp`.
