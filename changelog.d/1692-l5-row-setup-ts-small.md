### Changed
- **Fifteen small L5 rows set up their state in TypeScript** (GH 1692, wave 3 part 4a). `run-l5.ts` now runs a row's `setup-l5.ts` under node when one exists and falls back to `setup-l5.sh` otherwise, naming the file that failed. The new `tests/l5-l6/lib/setup-helpers.ts` gives the row scripts `writeFile`, `gitCommit` and `sql` (through `node:sqlite`, bound parameters, foreign keys off as the sqlite3 CLI has them), and the ported scripts write the same files, commits and rows the bash ones did. The seven rows whose setup did nothing lose their script. The cheatcode rows no longer export the `TMB_CHEATCODE_*_FIXTURE` variables, which never reached the claude run; the trajectory-server reads the project-root fixture files they write. `setup-helpers.test.ts` runs every row's `setup-l5.ts` against a seeded scratch project as an L3 step of `tests/run-all.sh`.
