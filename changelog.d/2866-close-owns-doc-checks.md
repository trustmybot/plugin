### Changed
- **swe fixes a missing changelog fragment or a stale doc reference before it closes, not after review starts** (GH 2866): the changelog and stale-doc checks moved from the code-reviewer spawn to swe's close gate. That gate runs them on the worktree HEAD against its merge base with the PR target, before it reuses a run or runs verification[], and a waiver or the preflight bypass does not skip them. Where they look is now your project's: `.config/tmb/doc-checks.json` names the changelog directory, the doc globs, and the tool source globs and name pattern. Without the file, or without a key, that check is skipped and the close says which key to add; an invalid file blocks the close and shows the expected shape. The code-reviewer preflight keeps the commit, passing-run and base-conflict checks. When swe stops with commits but no passing verification run for HEAD, its task is no longer auto-completed: it stays open and bro is told to resume the swe so the work closes through the gate.
Metric: swe_rework_ratio lower
