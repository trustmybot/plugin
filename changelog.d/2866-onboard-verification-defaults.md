### Added
- **`/onboard` proposes repo checks from your env profile** (GH 2866): a repo with no `.config/tmb/verification-defaults.json` got no repo checks at task close, so CI found what a local run could have caught. `/onboard` now offers the lint, typecheck and test commands from the repo's recorded env profile, writes the ones you pick to that file in your working tree (never committing it or replacing an existing one), and says to commit it to the PR target. Task provision, task retry and `/scan` now say when the file is missing and point to `/onboard`; the hint never blocks.
