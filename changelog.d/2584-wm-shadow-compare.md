### Added
- **The world model checks itself against a clean rebuild once a day and rebuilds when they differ** (GH 2584): when the trajectory server starts, its catch-up now also picks one repo not checked in the last 24 hours and, in the background, builds a fresh index of it at the same commit in a temporary database, then compares its files, symbols and edges with the live index. A match is recorded and nothing else changes. A difference is recorded too, in a new `wm_shadow_compare` audit row and a `wm_reindex` row with mode `mismatch`, and the next world-model read rebuilds that repo in full. The temporary database is always deleted, the live index is never touched by the check, and nothing is filed on GitHub. If the index moves to a new commit while the check runs, the result is skipped.
