### Security
- **A trajectory-server call's `agent` argument must name the real caller** (GH 1290): the server's role gates (`requireRoles`, the audit writers) trusted the `agent` argument, so a pr-reviewer or consultant could pass `agent='bro'` and call bro-only tools or author bro audit rows. The new `agent-arg-matches-caller` PreToolUse hook compares `agent` with the payload's `agent_type` (bro when the main session calls), after the shared role normalisation, and denies a mismatch with a reason naming the tool and both values plus an `agent_arg_mismatch` audit row (`tool`, `given`, `actual`, `task_id`). A matching or missing `agent` is never denied, and the decision does not depend on the trajectory DB.
