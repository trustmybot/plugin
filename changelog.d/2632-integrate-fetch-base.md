### Fixed
- **`cli.js integrate` no longer hangs on a stuck base fetch, and same-file renames no longer stop its rebase** (GH 2632, GH 2356): the base fetch added for a stale local base (GH 2198) now gives up after 60 s (`TMB_INTEGRATE_FETCH_TIMEOUT_MS` overrides it), so an ssh remote that hangs exits 4 with a timeout message, leaving the branch and the DB unchanged. The rebase also runs with rename detection off (`-c merge.renames=false`), so two sides renaming the same generated file differently no longer stop it on a rename/rename conflict; the patch-id check still judges the result.
