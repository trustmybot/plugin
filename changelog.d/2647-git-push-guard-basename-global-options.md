### Fixed
- **git-push-guard sees `/usr/bin/git push` and reads past every git global option** (GH 2647): the guard took git only as the bare word `git`, so `/usr/bin/git push` or `./git push` from a `.claude/worktrees/` checkout went through unchecked, and it did not know `--attr-source` or `--super-prefix` take a value, so `git --attr-source HEAD push` read `HEAD` as the subcommand. git now counts by its basename, every value-taking global option from `git --help` skips its argument (also when finding the dir of `git -C`), and an option word before the subcommand that is none of git's known global options leaves the subcommand unknown, which the guard denies.
