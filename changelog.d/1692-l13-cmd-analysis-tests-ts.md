### Changed
- The cmd-analysis l3 tests are now node:test files that run in `npm test` with every assertion kept (GH 1692). `mcp/trajectory-server/src/test/cmd-analysis-l3-helpers.test.ts` (273 cases, plus the bounded-run watchdog and one divergence check), `cmd-analysis-l3-write-paths.test.ts` (190), `cmd-analysis-l3-loops.test.ts` (111), `cmd-analysis-l3-programs.test.ts` (173) and `cmd-analysis-l3-python-runners.test.ts` (210) cover the bash `tests/l3-integration/hooks/cmd-analysis.test.sh`, which is gone. Each group runs its cases through one bash process that sources `scripts/hooks/lib/cmd-analysis.sh`, and 597 of them also run through the TS cmd-analysis module and must agree. The shared harness lives in `cmd-analysis-l3.ts`, and `run-bounded-child.ts` replaces the perl `run_bounded` timeout. A command listed in `tests/fixtures/cmd-analysis/divergences.jsonl` is checked on bash only, because `cmd-analysis-diff` already checks its recorded TS answer.
- The TS cmd-analysis module refuses `cat <<A <<B` (two heredocs opened on one line) because tree-sitter-bash cannot parse it, while `cmd-analysis.sh` splits it into statements. This difference is now a recorded divergence (decision 703) with a corpus row and a unit test. No hook behaviour changes.
