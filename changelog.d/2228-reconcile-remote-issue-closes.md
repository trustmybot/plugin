### Fixed
- **Issues closed on GitHub/GitLab no longer stay open in the trajectory DB** (GH 2228): a PR merged outside a session (web or auto-merge) or an issue closed by hand left its DB issue open, because only an in-session `gh pr merge` closed it. The new bro tool `issue_reconcile_remote` reads the remote state of every open linked issue (batched `gh api graphql`, `glab issue view`), closes the ones whose remote is closed, and never writes to the remote; `dry_run` reports without writing. An issue whose tasks are still live stays open and is listed as deferred, and the new `issues_open_after_remote_close` doctor warning points back to the tool once those tasks close.
