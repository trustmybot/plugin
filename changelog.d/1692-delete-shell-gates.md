### Removed
- **The bash hook gates and `dispatch.sh` are gone** (GH 1692): the 59 `scripts/hooks/<gate>.sh` scripts, `scripts/hooks/dispatch.sh`, `scripts/hooks/lib/persona.sh` and `scripts/hooks/lib/scope-fence.sh` are deleted, since the TypeScript router (`node mcp/trajectory-server/dist/hooks.js <Event> [part]`) runs every gate from `mcp/trajectory-server/src/hooks/<gate>.ts`. `TMB_HOOKS_IMPL=bash` has nothing left to select. The shared shell helpers in `scripts/hooks/lib/` stay for the scripts that still source them. The l1 lints `hook-onfailure`, `hook-timeout-budget`, `hooks-doc-fresh`, `valid-permission-decisions` and `hook-tests-pin-project` now judge the TypeScript gates, `no-bare-role-compare` checks only the shell libs, `hooks-via-dispatcher` and `agent-spawn-chain-doc` are deleted, and the node lint `no-retired-hook-gate-paths.test.mjs` fails on any citation of a deleted gate path. A project whose headless shim still has per-gate entries from before v1.2.0 now gets a `failing OPEN` warning from them until `/onboard` rewrites the shim. Hook behaviour is unchanged.
