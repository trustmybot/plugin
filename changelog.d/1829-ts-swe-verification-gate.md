### Changed
- **The swe verification gate also runs in TypeScript** (GH 1692, GH 1829): `swe-verification-gate` is ported to the trajectory-server hook bundle with the same deny texts, verification run rows and timeout semantics as the shell gate, which stays the registered hook. Unlike the shell gate, the port needs neither jq nor the sqlite3 CLI, so on a machine without them it still runs verification[] and denies a failing command where the shell gate let every completion through. The gate's l3 suite now ignores a `TMB_VERIFICATION_TIMEOUT_S` or `TMB_VERIFICATION_TAIL_CHARS` inherited from the environment it runs in, so it passes when run from inside a verification run.
