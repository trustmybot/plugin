### Security
- **A rebased task commit no longer ships on the strength of its original review** (GH 1518): `git-push-guard.sh` checked only pushed commits that were some task's `commit_sha`, so the same work rebased onto a newer base was pushed unchecked. The guard now matches pushed commits to task commits by `git patch-id --stable`. A rebased commit of a task with no passing review is denied. A rebased commit of a reviewed task is denied unless a passing verification run is recorded for that exact SHA. The new `skills/tmb_planning/scripts/integrate.sh <task_id> <base>` is bro's way to produce such a commit. It refuses a task without a passing review, rebases in a temporary worktree, refuses a conflict or a patch-id change, re-runs `verification[]` on the rebased commit, records the run, and moves the branch only when the run passes. Commits that match no task are unaffected.
