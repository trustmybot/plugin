### Security
- **Cheatcode installs and uninstalls no longer touch your user-scope Claude Code settings** (GH 1533): `cheatcode-uninstall.sh` now runs `claude plugin uninstall <name> --scope project --keep-data` and `claude mcp remove <name> --scope project`, and `cheatcode-install.sh` adds MCP servers with `claude mcp add --scope project` (the project's `.mcp.json`) and refuses `--scope global` with `outside_project` before calling `claude`. Before, these calls fell back to CLI defaults that reach user scope or `~/.claude.json`. `heal-mcp-cache.sh` now refuses to run inside Claude Code (`CLAUDE_PROJECT_DIR` or `CLAUDE_PLUGIN_ROOT` set) instead of carrying on after a 3 s warning; quit Claude Code and run it from a terminal. A new L1 lint, `tests/l1-lint/cli-config-scope.sh`, fails any config-changing `claude plugin` / `claude mcp` call without `--scope project`. A cheatcode MCP server installed by an earlier version lives in local scope, so uninstalling it now reports `removed=false`; remove it with `claude mcp remove <name> --scope local`.
