### Fixed
- **Scans stop registering scratch repos and clear their stale rows** (GH 1551): `/scan` registered every git repo below the project, so a scratch repo a test run left behind (such as `.tmp-l6-persona/proj`) became a project repo, and its row stayed after the dir was gone. The scan now skips a repo below the project whose path has a dot-prefixed dir, that an enclosing repo's `.gitignore` ignores, or that has no commit, and records each skip once as a `scan_skipped` audit row naming the path and reason. A repo row under the project that the scan no longer finds is deleted unless a task still references it; such a row is kept and listed in the scan result's `repos_stale_kept`. A new lint fails when the plugin checkout holds a `.tmp-*` dir at its root.
