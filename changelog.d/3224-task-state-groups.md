### Changed
- **Task status readers test named state groups** (GH 3224): the dashboard server, the trajectory-server tools, the CLI and the hooks no longer compare a task's status to a hand-written list of states. Each reader now asks one module, `task-states.ts`, whether the status is in a named group (live, in progress, awaiting close, done, terminal and a few more), and that module draws every state from the one list of task statuses. Every count, gate and report reads the same tasks as before; when the lifecycle's states are renamed, the readers pick the change up from that one module.
