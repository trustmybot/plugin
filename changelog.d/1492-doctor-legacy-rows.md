### Fixed
- **`trajectory_doctor` no longer warns about rows written before today's writers** (GH 1492): on a DB carried over from v1.0.x, `waiver_not_duplicated` counted the duplicate `verification_gate_waived` rows swe used to write itself, and `populated_agent_runs_session_id` / `_model` / `_root_dir` counted runs opened before the server stamped those columns. The schema v39 migration re-types each later legacy duplicate as `legacy_event` (the first row of each task stays, nothing is deleted), and the three `populated_agent_runs_*` contracts now count only runs started at or after the first run carrying a `root_dir`. Their limits are unchanged, so a new duplicate waiver or a new run missing those columns still shows up.
