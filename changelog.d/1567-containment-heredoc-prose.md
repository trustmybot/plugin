### Fixed
- **A heredoc program whose text quotes a path is no longer blocked for it** (GH 1567): when a python / node / perl / ruby program fed through a heredoc wrote through a variable, the containment guard counted every quoted path-like token, including one quoted inside a larger string such as `"/onboard"` in a triple-quoted block of shell text, and denied the edit as a write to `/onboard`. Each string literal of the program is now judged whole, so a path mentioned inside a larger string no longer counts; a standalone path literal still does, and a program that does not parse still counts every quoted token.
