### Changed
- **The Project map reads like a GitHub repository browser, and its dependency graph follows light and dark mode** (GH 1790): a repository picker, a file-tree sidebar you can drive with the arrow keys, and a listing of the selected directory with a clickable breadcrumb, a file count and each subdirectory's summary. World-model search results open the directory they point at. The dependency graph now takes its colours from the theme, so it switches with the colour mode, and each file's language tag carries a colour dot. On a phone everything stacks and the graph scrolls inside its own box.
