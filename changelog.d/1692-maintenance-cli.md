### Changed
- **The maintenance tools heal-mcp-cache, trajectory-doctor and backfill-agent-runs are now `cli.js` subcommands** (GH 1692): run `node --experimental-sqlite <plugin>/mcp/trajectory-server/dist/cli.js heal-mcp-cache [--channel stable|rc|dev] [--dry-run]`, `... cli.js trajectory-doctor [--db <path>] [--ids <id,...>] [--record]` and `... cli.js backfill-agent-runs [--apply] [--since <ISO>] [--transcripts-dir <dir>]` in place of `scripts/maintenance/heal-mcp-cache.sh`, `trajectory-doctor.sh` and `backfill-agent-runs.sh`. Flags, prompts and their defaults, dry-run output and exit codes are unchanged, apart from two things. A flag given with no value now exits 2 (the documented usage-error code) instead of 1. heal-mcp-cache no longer needs `jq`. The bundle runs from the plugin cache with no `node_modules`. The L5/L6 gate and the L0 upgrade smoke call `cli.js trajectory-doctor`, and the shell tests of these tools move to node:test (`src/test/cli-heal-mcp-cache.test.ts`, `cli-maintenance-no-db.test.ts`, `cli-maintenance-db.test.ts`).

### Removed
- **`scripts/maintenance/cleanup-stale-worktrees.sh`** (GH 1692): this no-op one-time cleanup is deleted. `cli.js health` no longer suggests it when it finds stale TMB state.
