### Added
- **Bro can draft a TMB bug report you review before anything is filed** (GH 2034): the new `bug_report_draft` tool writes a report for github.com/trustmybot/plugin with a title, a body in the form's layout, an environment block (TMB version and channel, Claude Code, OS, shell, Node, project shape, branching, issue sync, session, sandbox), a dedup signature and a prefilled new-issue link. Before you see it, paths, tokens and key blocks (PEM and PGP), emails, remotes, and your repo, branch and issue names are stripped. It only drafts when you said yes in `/onboard` or asked for this report, and it never files anything itself. Once bro files an approved report, a later draft of the same error points to the earlier one.
