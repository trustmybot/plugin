### Added
- **A repo's toolchain evidence, and a `repo_env` table to keep the commands bro picks from it** (GH 2066): `env_detect` (any agent) reads a repo's manifests, lockfiles, config files, CI steps and task-runner targets per package root and returns them with an `evidence_hash`, without running anything; it also compares each stored profile's hash and reports `drifted`. `env_record` (bro only) upserts the profiles bro resolves from that evidence into the new `repo_env` table (schema v58): install, test, lint, format-check and typecheck command candidates with their provenance, plus overrides, waivers and declined items that survive a later re-record. `env_get` returns the stored profiles with `effective_commands`, the overrides merged over the detected commands.
