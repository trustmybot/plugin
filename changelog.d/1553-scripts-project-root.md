### Fixed
- **Scripts and hook hints name the right project and worktree from any working directory** (GH 1553): the skill fallback scripts (`bro-sqlite-readonly.sh`, `validation-record-fallback.sh`), `health.sh`, the SessionStart inventory, the stay-on-base deny and the spawn hint used to read `$PWD` as the project. Run from `/` or from inside a worktree, they read the wrong DB, created a stray `.claude` dir, or printed relative worktree paths. They now resolve the project from `CLAUDE_PROJECT_DIR` and the trajectory DB. The fallback scripts report `db-not-found` with a hint instead of guessing. The inventory lists each registered repo's stack, branch and recent commits. The deny and spawn hint give the absolute worktree path from the task's `repos` row (or `unresolved (<reason>)`). `health.sh` skips the duplicate-plugin check with a WARN when no project resolves. The persona context now carries a `Project root (<project> in TMB prompts):` line. `bump-version.sh` and `install-merge-driver.sh` (with no argument) act on the checkout holding the script; the latter targets that repo's main checkout. `await_release_gate` now takes the repo dir as argument 2, so the optional timeout moves to argument 3; no caller passed a timeout.
