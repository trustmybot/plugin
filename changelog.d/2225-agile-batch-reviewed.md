### Added
- **A grouped code review clears queued agile tasks** (GH 2225): code-reviewer can record one verdict for a group of queued agile tasks reviewed together on a feature branch, with the new `review_batch_record` tool. Every task in the group must be a closed agile task still queued at its current commit and not yet reviewed this way, and its commit must be part of the reviewed feature-branch commit; the reviewer must not have built any of them. Otherwise nothing is recorded. A pass marks every task reviewed, which takes it out of the review queue, the doctor's agile backlog and the issue-close check for unreviewed tasks; a fail leaves them all queued. Recovering a stuck agile task with `task_recover` now queues it for review too, where before it dropped out of the queue unreviewed.
