### Changed
- **Installing the MCP server's transformers no longer rebuilds other plugin versions' bridges that are already in place** (GH 1716): after each install, every other cached plugin version's `node_modules` was deleted and its `@huggingface/transformers` bridge re-created, even when that `node_modules` held nothing but the bridge an earlier run wrote. Such a version is now left as it is. Its link is re-pointed in place, through an atomic swap, when it targets a different key than the one the version pins and that key is installed. Any other `node_modules` is still replaced as before.
