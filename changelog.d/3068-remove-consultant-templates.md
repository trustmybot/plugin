### Removed
- **The architect, cto, ceo and pm consultant templates are gone** (GH 3068): the plugin no longer ships `templates/agents/architect.md`, `cto.md`, `ceo.md` or `pm.md`, and a fresh trajectory DB seeds only the `swe` and `code-reviewer` agents. `/tmb:agent-create` drafts any consultant, these four names included, from `templates/agents/template.md`. Schema v71 deletes an existing project's `architect`, `cto`, `ceo` and `pm` agent rows only while they still point at the deleted plugin files; a consultant you already copied into `.claude/agents/` keeps its row and file, and past runs, audit rows and discussions by those names stay as written.
- **`/tmb:agent-create` no longer has a template-copy path** (GH 3068): `agent_resolve` now returns only `collision` (the project file exists) or `from-scratch` (draft from `templates/agents/template.md`), so asking for a consultant named `template` drafts from the scaffold instead of copying it verbatim.
