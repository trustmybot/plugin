### Added
- **Every task and every swe / pr-reviewer run records its reasoning effort, and the spawn gate enforces it** (GH 1349): schema v37 adds `tasks.effort` (`low` | `medium` | `high`, default `medium`) and a nullable `agent_runs.effort`. `task_create_batch` and `task_provision` take an optional `effort`; omitted, it is `plugin_config.swe_default_effort` (`medium` when unset), and any other value is a `typed_field_violation`. `task_reopen` and `task_retry` take an optional `effort` so a rework can run at `high`, writing a `task_effort_raised` audit row when they raise it; `task_get`, `task_brief`, `task_provision` and `task_reopen` return it. The new `require-spawn-effort.sh` gate, run by `agent-spawn-dispatch.sh` right after `require-task-spec.sh`, denies a swe Agent call whose `effort` is not the task's and a pr-reviewer Agent call whose `effort` is not `plugin_config.reviewer_effort` (`high` when unset), naming the value to pass; it fails closed without jq or on a DB read error. At SubagentStop `swe-atomic-close.sh` copies the task's effort onto the swe `agent_runs` row and now also meters pr-reviewer spawns, one row each carrying `reviewer_effort`, so review outcomes can be compared by effort. `config_set` refuses any other value for `swe_default_effort` and `reviewer_effort`; `trajectory_doctor` warns when SubagentStop-metered swe/pr-reviewer runs stop carrying an effort.
