### Changed
- **Insights charts share the agent colours, Verdict Mix leads with its pass rate, and dashboard labels use Title Case** (GH 2049): Insights no longer mixes purple, green, red and orange with the swe pink, code-reviewer orange and bro blue. Each chart now takes the hue of the agent whose work it measures, and data that belongs to no agent is blue. Verdict Mix now shows the pass percent and "232 of 303 review verdicts passed", the same layout as the First-Pass Rate and Verification Pass Rate tiles. Tabs, headings, card titles, column headers, options and buttons across the dashboard use Title Case (for example "Runs & Gates", "Cost by Model", "Last 30 Days"). Agent names stay lowercase, and sentences, captions and tooltips keep sentence case.
