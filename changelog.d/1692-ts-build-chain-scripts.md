### Changed
- **Build-chain maintenance scripts run as TypeScript** (GH 1692): `bump-version`, `dev-build-version`, `regen-generated` and the changelog-fragment library are now `.ts` files under `scripts/maintenance/`, run with `node --experimental-strip-types scripts/maintenance/<name>.ts` and the same arguments, output and exit codes. The `tmb-regen` merge driver installer moved into the hooks bundle: the WorktreeCreate hook installs it in-process, and maintainers run `node mcp/trajectory-server/dist/hooks.js install-merge-driver [repo-dir]`. The driver's stderr hint now names `regen-generated.ts`, and the WorktreeCreate golden recording carries the new string. `integrate.sh` runs `regen-generated.ts` and falls back to the shell script on an older base; the dev-build workflow, the changelog lint and the docs use the new commands.
