### Added
- **A task starts only in a ready environment** (GH 2866): `task_provision`, `task_reopen` and `task_retry` now run an environment gate before they write anything. It fetches the base from `origin` when the repo has one, cuts the branch, adds the worktree, runs the repo's `.config/tmb/worktree-setup.json` commands and reindexes the world model at the base commit. A failing stage refuses the call with `env_gate_failed` (`stage`, `detail`, `output_tail`), leaves the task untouched and removes the branch and worktree that call created, so swe no longer starts on a stale base or a broken setup. A successful call reports each stage in `env_gate` and records the base commit and world-model commit on the task (`base_sha`, `wm_commit`, schema v67). A server without a world model skips the reindex and says so in the decision.
Metric: swe_rework_ratio lower
