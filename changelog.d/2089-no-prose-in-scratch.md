### Changed
- **Prose files are denied in scratch folders and temp dirs** (GH 2089): a new gate denies writing a `.md`, `.markdown`, `.txt` or `.rst` file under `.claude/<plugin>/scratch/`, and under `/tmp` or `$TMPDIR` unless the target is in a git worktree. It also denies `gh issue|pr create|edit|comment` with `--body-file` or `-F` naming a file; `--body` and `--body-file -` on stdin still work. Its message points to the trajectory DB tools for plans, decisions and specs, and to a `.log` file for command output. It applies to every agent, deleting such a file stays allowed, and `TMB_ALLOW_PROSE_SCRATCH=1` lifts it. `trajectory_doctor` gains a `scratch_no_prose` warning that counts prose files already in the scratch folder.
