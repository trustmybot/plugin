### Fixed
- **Only the trajectory server upgrades your trajectory DB** (GH 1639): a maintenance script run from a shell could find the project's live DB on its own and migrate it to a newer schema, skipping the server's checks. Now only the MCP server migrates the DB. Any other opener stops on an older schema with a clear message, and it takes no backup and changes nothing. The scan scripts (`run-scan.mjs`, `run-scan-initial.mjs`) and the world-model smoke script never search for a DB: they need an explicit `TRAJECTORY_DB_PATH` and exit 2 without it. The post-close rescan and session-start prescan hooks pass that path for you. `run-scan.mjs` no longer crashes with a `TypeError` when the DB fails to open: it prints the error and exits 1.
