### Changed
- **`/onboard` recommends the Bash sandbox on macOS** (GH 1549): the sandbox question now defaults to Yes (Recommended) on the platform where the recorded network probe passed every command (macOS, Claude Code 2.1.303) and no remote is SSH; Linux and SSH remotes stay at No. The block it writes to `.claude/settings.local.json` now also sets `enableWeakerNetworkIsolation` on macOS so `gh` can reach the TLS trust service, which slightly weakens network isolation, and points npm's and bun's caches into `.claude/tmb/cache/` so `npm` and `bun add` work without opening `$HOME`. The release gate reruns the probe on macOS and fails on a regression.
